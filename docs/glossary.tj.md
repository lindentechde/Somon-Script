# Луғати истилоҳот (Глоссарий / Glossary)

Ин файл ҳар истилоҳи нав ва ҳар паёми навро, ки дар SomonScript барои хонандагон
нишон дода мешавад, бо маънои русӣ ва англисӣ ҷамъ мекунад. Истилоҳоте, ки
аллакай дар забон ҳастанд (`src/keyword-map.ts`, `src/builtin-names.ts`,
`src/cli/i18n/translations/tj.ts`), ҳамон тавр истифода мешаванд ва синоним
надоранд.

**⚠ — бояд забондони тоҷик санҷад.** Муаллифи ин сатрҳо забондони тоҷик нест;
сатрҳое, ки бо ⚠ ишора шудаанд, пеш аз нишон додан ба омӯзгорон бояд аз ҷониби
забондон санҷида шаванд. (⚠ — строки, которые должен проверить носитель языка.)

## Қиматҳои махсус дар чоп (Значения при выводе / Printed values)

`чоп(…)` ва `чоп.сабт(…)` дар `somon run` ва дар майдони озмоиш ин қиматҳоро бо
номҳои SomonScript чоп мекунанд (`src/runtime/format.ts`).

| Тоҷикӣ         | Русский                  | English     | Эзоҳ                                        |
| -------------- | ------------------------ | ----------- | ------------------------------------------- |
| `дуруст`       | истина                   | `true`      | калимаи калидӣ                              |
| `нодуруст`     | ложь                     | `false`     | калимаи калидӣ                              |
| `холӣ`         | пустое значение (`null`) | `null`      | калимаи калидӣ                              |
| `беқимат`      | нет значения             | `undefined` | калимаи калидӣ                              |
| `ғайрирақам`   | не число                 | `NaN`       | ⚠ нав; варианти дигар: «рақам нест»        |
| `беохир`       | бесконечность            | `Infinity`  | ⚠ нав; `-беохир` барои `-Infinity`         |
| `функсия`      | функция                  | function    | `[функсия ном]` — функсия ҳангоми чоп       |
| `синф`         | класс                    | class       | `[синф Ном]` — синф ҳангоми чоп             |
| `даврӣ`        | циклическая ссылка       | circular    | ⚠ `[даврӣ]` — объект худашро дар бар дорад |
| `рӯйхат`       | массив                   | array       | `[рӯйхат]` — рӯйхати хеле чуқур             |
| `объект`       | объект                   | object      | `[объект]` — объекти хеле чуқур             |
| `ҷои холӣ`     | пустой элемент           | empty item  | ⚠ `<2 ҷои холӣ>` — дар рӯйхати `[1, , 3]`  |
| `унсур`        | элемент                  | item        | ⚠ `... боз 5 унсур` — пас аз 100 унсур     |
| `ҳисобшаванда` | вычисляемое свойство     | getter      | ⚠ `[ҳисобшаванда]`                         |

## Паёмҳои иҷро (Сообщения при запуске / Run-time messages)

| Тоҷикӣ                   | Русский                         | English                  | Эзоҳ                          |
| ------------------------ | ------------------------------- | ------------------------ | ----------------------------- |
| `Тасдиқ нашуд: …`        | Утверждение не выполнено: …     | Assertion failed: …      | ⚠ `чоп.тасдиқ(шарт, паём)`   |
| `Огоҳӣ: файл.som:3:5: …` | Предупреждение: файл.som:3:5: … | Warning: file.som:3:5: … | огоҳии компилятор пеш аз иҷро |

## Истилоҳоти паёмҳои компилятор (Термины сообщений компилятора / Compiler message terms)

Паёмҳои хато ва огоҳии компилятор (`compile(…, { language: 'tj' })`,
`somon --lang tj …`) аз ин калимаҳо сохта шудаанд.

| Тоҷикӣ                     | Русский                     | English            | Эзоҳ                                             |
| -------------------------- | --------------------------- | ------------------ | ------------------------------------------------ |
| хато                       | ошибка                      | error              | дар CLI мавҷуд буд                               |
| огоҳӣ                      | предупреждение              | warning            | дар CLI мавҷуд буд                               |
| маслиҳат                   | подсказка                   | hint               | ⚠ нав                                           |
| сатри 4                    | строка 4                    | line 4             | «сатр» ҳам номи навъи `сатр` аст                 |
| қавс; қавси пӯшанда        | скобка; закрывающая скобка  | bracket; closing … | ⚠ «пӯшанда» — пӯшонанда?                        |
| нохунак                    | кавычка                     | quotation mark     | ⚠                                               |
| қолаби матнӣ               | шаблонная строка            | template string    | ⚠                                               |
| шарҳ                       | комментарий                 | comment            | ⚠                                               |
| ифода                      | выражение                   | expression         | аз `tsc-messages-tj.ts`                          |
| эълон кардан               | объявить                    | declare            | аз `tsc-messages-tj.ts`                          |
| мувофиқ нест               | не совместим, не подходит   | is not assignable  | аз `tsc-messages-tj.ts`                          |
| Шояд … дар назар доштед?   | Может быть, вы имели в виду | Did you mean …?    | ⚠ `tsc-messages-tj.ts`: «Шояд … дар назар буд?» |
| Барнома компайл нашуд      | Программа не скомпилирована | did not compile    | ⚠                                               |
| давра                      | цикл                        | loop               | ⚠                                               |
| калимаи махсуси JavaScript | зарезервированное слово     | reserved word      | ⚠                                               |

## Ҳамаи паёмҳо (Все сообщения / All messages)

Ин ҷадвалро `node scripts/glossary-messages.js` аз каталоги паёмҳо
(`src/diagnostics`) месозад; онро дастӣ иваз накунед. **Ҳамаи сатрҳои тоҷикии ин
ҷадвал нав мебошанд ва бояд аз ҷониби забондон санҷида шаванд (⚠).** Паёмҳое,
ки матни англисиашон ба ҷои шарҳ омадааст (`detail`), дар забони англисӣ шарҳи
компиляторро нишон медиҳанд.
