# Дастур барои омӯзгор

Ин дастур барои омӯзгороне аст, ки бо [дарсҳои SomonScript](tj/README.md) дарс
мегузаранд. Барои кор бо майдони озмоиш донистани забони англисӣ, Node.js ё
сатри фармон лозим нест.

## 1. Майдони озмоиш

Майдони озмоиш - саҳифаи <https://lindentechde.github.io/Somon-Script/>. Дар он
хонанда барномаро менависад, тугмаи **▶ Иҷро**-ро пахш мекунад ва натиҷаро
мебинад. Хатоҳо бо забони тоҷикӣ, бо рақами сатр ва маслиҳат нишон дода
мешаванд. Забони саҳифаро ба русӣ ё англисӣ иваз кардан мумкин аст.

Барномаи хонанда ва вуруди он дар браузери ҳамон компютер нигоҳ дошта мешаванд:
пас аз пӯшидан ва боз кушодани саҳифа барнома боқӣ мемонад.

### Бе интернет, аз флешка

Майдони озмоиш як файл аст (`index.html`, тақрибан 1 МБ), ки ҳамаи қисмҳояш дар
худи он мебошанд. Онро як бор аз интернет гирифта, баъд бе интернет истифода
бурдан мумкин аст:

1. Дар компютере, ки интернет дорад, саҳифаи
   <https://lindentechde.github.io/Somon-Script/>-ро кушоед.
2. Дар поёни саҳифа пайванди **«⬇ Захира барои кор бе интернет»**-ро пахш
   кунед. (Ё **Ctrl+S**-ро пахш карда, саҳифаро ҳамчун «Веб-саҳифа, танҳо HTML»
   захира кунед.)
3. Файли захирашударо ба флешка нусха кунед.
4. Дар ҳар компютери синф файлро аз флешка (ё пас аз нусха ба мизи корӣ) бо
   браузер кушоед - масалан, бо ду пахш.

Барои ин ҳуқуқи маъмур (администратор) ва насб кардани барнома лозим нест.

Майдони озмоиш дар Chromium санҷида шудааст. Дар браузерҳои кӯҳна он шояд кор
накунад; дар он ҳолат браузери навтарро истифода баред. Агар браузер барномаро
иҷро карда натавонад, саҳифа инро бо паём мегӯяд.

Агар Node.js насб бошад, файлро аз рамзи сарчашма низ сохтан мумкин аст:
`npm run build:playground` (файл дар `playground/dist/index.html`).

## 2. Дарсҳо ва супоришҳо

- 18 дарс аз `чоп` то объектҳо: [мундариҷа](tj/README.md) (ба русӣ:
  [оглавление](ru/README.md)).
- Ҳар дарс 2–3 намуна дорад; пайванди «▶ Дар майдони озмоиш иҷро кунед»
  намунаро дар майдони озмоиш мекушояд (бо интернет).
- Ҳар дарс 3–4 супориш дорад: [ҳамаи масъалаҳо](tasks/README.md). Саҳифаи
  масъала шарт, мисоли вуруд ва натиҷа ва пайванд ба майдони озмоиш дорад.

### Тақсими супоришҳо

- **Бо интернет:** пайванди масъала ё намунаро ба хонандагон фиристед. Хонанда
  метавонад барномаи худро бо тугмаи **🔗 Пайванд** ба шумо фиристад: пайванд
  барнома ва вуруди онро дар бар мегирад.
- **Бе интернет:** ҳамаи 63 масъала дар худи майдони озмоиш ҳастанд, дар рӯйхати
  **«Масъала»** (аз рӯи дарсҳо). Хонанда масъаларо интихоб мекунад: шарти он,
  барномаи аввала ва вурудҳои санҷиш худ пайдо мешаванд, ва тугмаи **✓
  Санҷидан** барномаро бо ҳамаи санҷишҳо месанҷад - дар файли аз флешка
  кушодашуда ҳам. Ба хонандагон танҳо рақами масъаларо гӯед, масалан «05-jam».

### Санҷиши супоришҳо

- **Дар майдони озмоиш:** масъаларо аз рӯйхати **«Масъала»** интихоб кунед, ё
  пайванди «▶ Дар майдони озмоиш ҳал кунед»-ро дар саҳифаи масъала кушоед.
  Хонанда барномаро менависад ва тугмаи **✓ Санҷидан**-ро пахш мекунад: барнома
  бо ҳар санҷиш иҷро мешавад ва майдони озмоиш мегӯяд, ки кадомаш дуруст аст ва
  дар кадомаш чӣ интизор буд ва барнома чӣ чоп кард. Ин дар браузер кор мекунад,
  бе Node.js; пайванд санҷишҳоро дар худ дорад, бинобар ин тугма пас аз захира
  кардани пайванд ҳам мемонад.
- **Дастӣ:** натиҷаи барномаро бо натиҷаи мисол дар саҳифаи масъала муқоиса
  кунед. Вуруди дигарро низ санҷед: санҷишҳо дар ҷузвдони `tests` мебошанд
  (`1.in` - вуруд, `1.out` - натиҷаи интизорӣ).
- **Худкор:** агар дар компютери омӯзгор Node.js бошад, рамзи сарчашмаи
  SomonScript-ро аз GitHub гиред, `npm install` ва `npm run build`-ро як бор
  иҷро кунед. Баъд барномаи хонанда бо ҳамаи санҷишҳо чунин санҷида мешавад:

  ```bash
  npm run check-task -- 05-jam барнома.som
  ```

  Ҷавоб мегӯяд, ки кадом санҷиш гузашт ва дар кадомаш барнома чӣ чоп кард.

- Ҳалли намунавии ҳар масъала дар файли `hal.som` аст.

### Дарсҳоро чӣ тавр истифода бурдан мумкин

- **Дар синфи 10** - ҳамчун машқ ба бобҳои 1, 2 ва 4: хонанда ҳамон барномаҳоро
  бо забоне менависад, ки калимаҳояш тоҷикӣ мебошанд; майдони озмоиш хатоҳоро ба
  забони тоҷикӣ мефаҳмонад ва бе интернет ва бе насби Python кор мекунад.
  Барномаи Python-и китобро ба SomonScript навиштан мумкин аст: `print` - `чоп`,
  `input()` - `хондан()`, `int(input())` ва `float(input())` - `хонданиРақам()`,
  `if … elif … else` - `агар … вагарна агар … вагарна`,
  `for i in range(1, n + 1)` - `барои (тағ и = 1; и <= н; и++)`, `while` - `то`,
  `and`, `or`, `not` - `&&`, `||`, `!`, `x in a` - `а.дорад(х)`, `len(a)` -
  `а.дарозӣ`, `math.sqrt` - `Риёзӣ.дуръшака`.
- **Пас аз синфҳои 5 ва 6** - ҳамчун қадами баъдӣ пас аз алгоритмҳо ва Scratch:
  ҳамон алгоритмҳои хаттӣ, шоханок ва такроршаванда, вале дар матни барнома.
- **Дар синфҳои 7 ва 8**, ки дар китобҳояшон барномасозӣ нест, - масалан, дар
  маҳфил.
