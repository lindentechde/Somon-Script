# Дарси 3. Тағйирёбандаҳо

**Дар ин дарс:** қиматҳоро дар тағйирёбандаҳо нигоҳ медоред ва онҳоро иваз
мекунед.

## Тағйирёбанда чист?

Тағйирёбанда — қуттие бо ном, ки дар он қимат нигоҳ дошта мешавад. Онро бо
калимаи `тағ` эълон мекунем:

```som
тағ ном = "Зарина";
тағ синну = 13;
чоп(ном);
чоп(синну);
чоп(ном, "—", синну, "сола");
```

[▶ Дар майдони озмоиш иҷро кунед](https://lindentechde.github.io/Somon-Script/#c=0YLQsNKTINC90L7QvCA9ICLQl9Cw0YDQuNC90LAiOwrRgtCw0pMg0YHQuNC90L3RgyA9IDEzOwrRh9C-0L8o0L3QvtC8KTsK0YfQvtC_KNGB0LjQvdC90YMpOwrRh9C-0L8o0L3QvtC8LCAi4oCUIiwg0YHQuNC90L3RgywgItGB0L7Qu9CwIik7Cg)

- `тағ ном = "Зарина";` — тағйирёбандаи `ном`-ро эълон мекунад ва ба он қимати
  `"Зарина"`-ро медиҳад.
- `чоп(ном)` — қимати тағйирёбандаро чоп мекунад, на калимаи «ном»-ро.

## Қиматро иваз кардан

```som
тағ хол = 10;
чоп(хол);
хол = 15;
чоп(хол);
хол = хол + 5;
чоп(хол);
```

[▶ Дар майдони озмоиш иҷро кунед](https://lindentechde.github.io/Somon-Script/#c=0YLQsNKTINGF0L7QuyA9IDEwOwrRh9C-0L8o0YXQvtC7KTsK0YXQvtC7ID0gMTU7CtGH0L7QvyjRhdC-0LspOwrRhdC-0LsgPSDRhdC-0LsgKyA1OwrRh9C-0L8o0YXQvtC7KTsK)

- `хол = 15;` — қимати навро медиҳад; `тағ` дигар лозим нест.
- `хол = хол + 5;` — қимати ҳозираро гирифта, 5 илова мекунад ва натиҷаро боз
  дар `хол` нигоҳ медорад.

## Собит

Қимате, ки иваз намешавад, бо `собит` эълон мешавад:

```som
собит рӯзҳоиҲафта = 7;
чоп("Дар як ҳафта", рӯзҳоиҲафта, "рӯз ҳаст");
```

[▶ Дар майдони озмоиш иҷро кунед](https://lindentechde.github.io/Somon-Script/#c=0YHQvtCx0LjRgiDRgNOv0LfSs9C-0LjSstCw0YTRgtCwID0gNzsK0YfQvtC_KCLQlNCw0YAg0Y_QuiDSs9Cw0YTRgtCwIiwg0YDTr9C30rPQvtC40rLQsNGE0YLQsCwgItGA06_QtyDSs9Cw0YHRgiIpOwo)

Агар ба `собит` қимати нав диҳед, майдони озмоиш хато нишон медиҳад.

## Номи тағйирёбанда

- Ном аз ҳарфҳо, рақамҳо ва `_` иборат аст ва бо ҳарф сар мешавад: `ном`,
  `хол2`, `шумораи_хонандагон`, `рӯзҳоиҲафта`.
- Номи фаҳмо интихоб кунед: `синну` беҳтар аз `х` аст.
- Калимаҳои калидиро (`тағ`, `агар`, `чоп` …) ҳамчун ном истифода набаред.

## Хатоҳои маъмул

- Тағйирёбандаро пеш аз эълон истифода бурдан: `чоп(х); тағ х = 1;`
- Як номро ду бор бо `тағ` эълон кардан.
- `чоп("ном")` навиштан ба ҷои `чоп(ном)`: нохунак матнро чоп мекунад.
