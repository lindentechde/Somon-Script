# Барномасозӣ бо SomonScript: дарсҳо барои навомӯзон

Ин дарсҳо барои касоне навишта шудаанд, ки ҳеҷ гоҳ барнома нанавиштаанд. Ҳар
дарс шарҳи кӯтоҳ, намунаҳо ва супоришҳо дорад. Намунаҳоро бо як пахш дар
**майдони озмоиш** иҷро кардан мумкин аст:
<https://lindentechde.github.io/Somon-Script/>. Насб кардани чизе лозим нест.

_Ин дарсҳо ба русӣ: [Уроки на русском](../ru/README.md)._

## Супоришҳо ва санҷиши онҳо

Ҳар супориш масъалаест бо санҷишҳо: [ҳамаи масъалаҳо](../tasks/README.md). Дар
саҳифаи масъала шарт, мисол ва пайванд ба майдони озмоиш ҳаст. Пайванд майдони
озмоишро бо санҷишҳои масъала мекушояд: тугмаи **✓ Санҷидан** барномаро бо ҳамаи
санҷишҳо месанҷад ва мегӯяд, ки кадомаш гузашт. Агар дар компютер Node.js ва
SomonScript насб бошанд, барномаро бо фармон ҳам санҷидан мумкин аст:

```bash
npm run check-task -- 05-jam барнома.som
```
