# Дарси 1. Барномаи аввал

**Дар ин дарс:** барномаи аввалро менависед, онро иҷро мекунед ва бо `чоп` матн
ва рақамҳоро ба экран мебароред.

## Барнома чист?

Барнома — рӯйхати фармонҳо барои компютер. Компютер фармонҳоро як-як, аз боло ба
поён иҷро мекунад.

## Майдони озмоиш

Барномаҳоро дар **майдони озмоиш** менависем ва иҷро мекунем:
<https://lindentechde.github.io/Somon-Script/>. Ин саҳифа дар браузер кушода
мешавад, насб кардани чизе лозим нест. Дар тарафи чап барнома навишта мешавад,
дар тарафи рост «Вуруд» ва «Натиҷа» ҳастанд. Тугмаи **▶ Иҷро** барномаро иҷро
мекунад.

## Фармони `чоп`

```som
чоп("Салом, ҷаҳон!");
```

[▶ Дар майдони озмоиш иҷро кунед](https://lindentechde.github.io/Somon-Script/#c=0YfQvtC_KCLQodCw0LvQvtC8LCDSt9Cw0rPQvtC9ISIpOwo)

- `чоп` он чиро, ки дар қавс аст, дар «Натиҷа» менависад.
- Матн дар нохунак `"…"` навишта мешавад. Матнро дар барномасозӣ **сатр**
  меноманд.
- Ҳар фармон бо `;` тамом мешавад.

## Якчанд сатр ва рақамҳо

```som
чоп("Ман барномасозиро меомӯзам.");
чоп("Ин барномаи аввали ман аст.");
чоп(2026);
чоп(2 + 3);
чоп("2 + 3");
```

[▶ Дар майдони озмоиш иҷро кунед](https://lindentechde.github.io/Somon-Script/#c=0YfQvtC_KCLQnNCw0L0g0LHQsNGA0L3QvtC80LDRgdC-0LfQuNGA0L4g0LzQtdC-0LzTr9C30LDQvC4iKTsK0YfQvtC_KCLQmNC9INCx0LDRgNC90L7QvNCw0Lgg0LDQstCy0LDQu9C4INC80LDQvSDQsNGB0YIuIik7CtGH0L7QvygyMDI2KTsK0YfQvtC_KDIgKyAzKTsK0YfQvtC_KCIyICsgMyIpOwo)

- Фармонҳо бо ҳамон тартибе, ки навишта шудаанд, иҷро мешаванд.
- Рақамҳо бе нохунак навишта мешаванд. `чоп(2 + 3)` ҷавобро чоп мекунад: `5`.
  `чоп("2 + 3")` бошад, матнро ҳамон тавр чоп мекунад: `2 + 3`.

## Якчанд қимат дар як сатр

```som
чоп("Ҷавоб:", 6 * 7);
чоп("Ман", 13, "сола ҳастам");
```

[▶ Дар майдони озмоиш иҷро кунед](https://lindentechde.github.io/Somon-Script/#c=0YfQvtC_KCLSttCw0LLQvtCxOiIsIDYgKiA3KTsK0YfQvtC_KCLQnNCw0L0iLCAxMywgItGB0L7Qu9CwINKz0LDRgdGC0LDQvCIpOwo)

Қиматҳое, ки бо вергул ҷудо шудаанд, дар як сатр бо фосила чоп мешаванд:
`Ҷавоб: 42`.

## Хатоҳои маъмул

- Нохунакро набастан: `чоп("Салом);`
- `Чоп` ё `chop` навиштан. Ҳарфҳои калон ва хурд фарқ мекунанд: танҳо `чоп`.
- Қавсро набастан: `чоп("Салом";`

Агар хато кунед, майдони озмоиш мегӯяд, ки хато дар куҷост. Дар дарси оянда
хондани ин паёмҳоро меомӯзем.
