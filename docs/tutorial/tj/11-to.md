# Дарси 11. Давраи `то`, `шикастан` ва `давом`

**Дар ин дарс:** давраеро менависед, ки шумораи даврҳояш пешакӣ маълум нест.

## `то`

`то (шарт) { … }` фармонҳоро то вақте ки шарт `дуруст` аст, такрор мекунад:

```som
тағ шумора = 5;
то (шумора > 0) {
  чоп(шумора);
  шумора = шумора - 1;
}
чоп("Оғоз!");
```

Дар дохили давра чизе бояд иваз шавад, то шарт рӯзе `нодуруст` шавад. Вагарна
давра беохир мешавад.

## Рақамҳои адад

```som
тағ адад = хонданиРақам();
тағ шумора = 0;
то (адад > 0) {
  адад = Риёзӣ.поён(адад / 10);
  шумора++;
}
чоп("Рақамҳо:", шумора);
```

## `шикастан`: аз давра баромадан

```som
// Рақамҳоро то 0 мехонад ва ҷамъи онҳоро чоп мекунад
тағ ҷамъ = 0;
то (дуруст) {
  тағ рақам = хонданиРақам();
  агар (рақам === 0) {
    шикастан;
  }
  ҷамъ += рақам;
}
чоп("Ҷамъ:", ҷамъ);
```

Вуруд:

```text
5
3
8
0
```

- `то (дуруст)` — давра худ тамом намешавад; аз он бо `шикастан` мебароем.
- `давом` давраи ҳозираро тамом карда, ба даври навбатӣ мегузарад.
