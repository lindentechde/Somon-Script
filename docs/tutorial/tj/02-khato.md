# Дарси 2. Хатоҳо ва шарҳҳо

**Дар ин дарс:** паёми хаторо мехонед ва хаторо ислоҳ мекунед; дар барнома шарҳ
менависед.

## Хато — ин муқаррарист

Ҳар барномасоз хато мекунад. Муҳим он аст, ки паёми хаторо хонда, онро ислоҳ
кунем. Ин барнома хато дорад — онро иҷро кунед:

```text
тағ синну = 15;
агр (синну > 14) {
  чоп("Шумо метавонед бозӣ кунед");
}
```

[▶ Дар майдони озмоиш иҷро кунед](https://lindentechde.github.io/Somon-Script/#c=0YLQsNKTINGB0LjQvdC90YMgPSAxNTsK0LDQs9GAICjRgdC40L3QvdGDID4gMTQpIHsKICDRh9C-0L8oItCo0YPQvNC-INC80LXRgtCw0LLQvtC90LXQtCDQsdC-0LfToyDQutGD0L3QtdC0Iik7Cn0K)

Майдони озмоиш чунин паём медиҳад:

```text
Хато дар сатри 2:
  Дар ин ҷо `{` интизор набуд: шояд пеш аз он `;` намерасад.
    2 | агр (синну > 14) {
      |                  ^
  Маслиҳат: Шояд `агар`-ро дар назар доштед?
Барнома компайл нашуд: 1 хато.
```

Паёмро чунин мехонем:

1. **Хато дар сатри 2** — хато дар кадом сатр аст. Рақами ин сатр дар чапи
   барнома сурх мешавад.
2. Баъд — **чӣ нодуруст аст**.
3. Сатри барнома ва аломати `^` — **дар куҷои сатр**.
4. **Маслиҳат** — чӣ тавр ислоҳ кардан мумкин аст. Ин ҷо `агар` нодуруст навишта
   шудааст: `агр`.

`агр`-ро ба `агар` иваз кунед ва боз иҷро кунед.

## Хато ҳангоми иҷро

Баъзе хатоҳо танҳо ҳангоми иҷрои барнома пайдо мешаванд. Онҳо **хатои иҷро** ном
доранд:

```som
тағ номҳо = ["Алӣ", "Зарина", "Фарҳод"];
чоп(номҳо[5].дарозӣ);
```

[▶ Дар майдони озмоиш иҷро кунед](https://lindentechde.github.io/Somon-Script/#c=0YLQsNKTINC90L7QvNKz0L4gPSBbItCQ0LvToyIsICLQl9Cw0YDQuNC90LAiLCAi0KTQsNGA0rPQvtC0Il07CtGH0L7QvyjQvdC-0LzSs9C-WzVdLtC00LDRgNC-0LfToyk7Cg)

Майдони озмоиш мегӯяд: «Хатои иҷро дар сатри 2», чӣ рух дод ва маслиҳат медиҳад.
Ин гуна хатоҳоро дар дарсҳои оянда беҳтар мефаҳмем.

## Шарҳ

Шарҳ — матне, ки компютер онро иҷро намекунад. Онро барои одамон менависем:

```som
// Ин барнома саломро чоп мекунад
чоп("Салом!"); // шарҳ метавонад дар охири сатр бошад

/* Шарҳи
   якчандсатра */
```

[▶ Дар майдони озмоиш иҷро кунед](https://lindentechde.github.io/Somon-Script/#c=Ly8g0JjQvSDQsdCw0YDQvdC-0LzQsCDRgdCw0LvQvtC80YDQviDRh9C-0L8g0LzQtdC60YPQvdCw0LQK0YfQvtC_KCLQodCw0LvQvtC8ISIpOyAvLyDRiNCw0YDSsyDQvNC10YLQsNCy0L7QvdCw0LQg0LTQsNGAINC-0YXQuNGA0Lgg0YHQsNGC0YAg0LHQvtGI0LDQtAoKLyog0KjQsNGA0rPQuAogICDRj9C60YfQsNC90LTRgdCw0YLRgNCwICovCg)

- `//` — шарҳ то охири сатр.
- `/* … */` — шарҳ дар якчанд сатр.

## Хатоҳои маъмул ва паёмҳои онҳо

| Хато                     | Паём                                       |
| ------------------------ | ------------------------------------------ |
| `чоп("Салом);`           | Нохунаки пӯшандаи `"` намерасад            |
| `чоп("Салом";`           | Қавси пӯшандаи `)` намерасад               |
| `агр (х > 1) {}`         | Маслиҳат: Шояд `агар`-ро дар назар доштед? |
| `чоп(ном);` бе `тағ ном` | Номи `ном` эълон нашудааст                 |
