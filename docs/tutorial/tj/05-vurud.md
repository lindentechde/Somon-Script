# Дарси 5. Вуруд: `хондан` ва `хонданиРақам`

**Дар ин дарс:** барнома маълумотро аз корбар мегирад.

## `хондан()`

`хондан()` як сатрро аз «Вуруд» мехонад:

```som
тағ ном = хондан();
чоп("Салом, " + ном + "!");
```

Вуруд:

```text
Алӣ
```

[▶ Дар майдони озмоиш иҷро кунед](https://lindentechde.github.io/Somon-Script/#c=0YLQsNKTINC90L7QvCA9INGF0L7QvdC00LDQvSgpOwrRh9C-0L8oItCh0LDQu9C-0LwsICIgKyDQvdC-0LwgKyAiISIpOwo&i=0JDQu9OjCg)

- Дар майдони озмоиш вурудро дар қисми **«Вуруд»** менависед: ҳар сатр — як
  вуруд.
- Ҳар даъвати `хондан()` сатри навбатиро мегирад.

## `хонданиРақам()`

`хондан()` ҳамеша **сатр** медиҳад. Барои ҳисоб `хонданиРақам()` лозим аст:

```som
тағ а = хонданиРақам();
тағ б = хонданиРақам();
чоп("Ҷамъ:", а + б);
```

Вуруд:

```text
2
3
```

[▶ Дар майдони озмоиш иҷро кунед](https://lindentechde.github.io/Somon-Script/#c=0YLQsNKTINCwID0g0YXQvtC90LTQsNC90LjQoNCw0pvQsNC8KCk7CtGC0LDSkyDQsSA9INGF0L7QvdC00LDQvdC40KDQsNKb0LDQvCgpOwrRh9C-0L8oItK20LDQvNGKOiIsINCwICsg0LEpOwo&i=MgozCg)

Агар ба ҷои `хонданиРақам()` `хондан()` нависед, натиҷа `23` мешавад, на `5`: ду
сатр пайваст мешаванд (дарси 4-ро ба ёд оред).

Агар дар вуруд рақам набошад, барнома бо хато қатъ мешавад: «`се` рақам нест:
`хонданиРақам()` рақам интизор буд». Рақамро бо нуқта ё вергул навиштан мумкин
аст: `2.5` ё `2,5`.

## Савол

Ба `хондан` ва `хонданиРақам` саволро додан мумкин аст. Он пеш аз хондан чоп
мешавад:

```som
тағ синну = хонданиРақам("Шумо чандсолаед? ");
чоп("Пас аз 5 сол шумо", синну + 5, "сола мешавед.");
```

Вуруд:

```text
13
```

**Дар супоришҳо савол нанависед:** санҷиш танҳо натиҷаро муқоиса мекунад.

## Агар вуруд тамом шавад

Агар барнома бештар аз он ки дар «Вуруд» ҳаст хонад, хато медиҳад: «Вуруд тамом
шуд». Ба барнома ҳамон қадар сатр диҳед, ки он мехонад.
