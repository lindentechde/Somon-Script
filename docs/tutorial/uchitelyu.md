# Памятка для учителя

Эта памятка — для учителей, которые ведут занятия по
[урокам SomonScript](ru/README.md). Для работы с песочницей не нужны английский
язык, Node.js или командная строка.

## 1. Песочница

Песочница — страница <https://lindentechde.github.io/Somon-Script/>. В ней
ученик пишет программу, нажимает **▶ Иҷро** («Запустить») и видит результат.
Ошибки показываются на таджикском, с номером строки и подсказкой. Язык страницы
можно переключить на русский или английский — тогда и сообщения будут на этом
языке.

Программа ученика и её ввод сохраняются в браузере этого компьютера: после
закрытия и повторного открытия страницы программа остаётся.

### Без интернета, с флешки

Песочница — это один файл (`index.html`, около 1 МБ), в котором есть всё нужное.
Его можно один раз взять из интернета, а потом пользоваться без него:

1. На компьютере с интернетом откройте
   <https://lindentechde.github.io/Somon-Script/>.
2. Внизу страницы нажмите ссылку **«⬇ Захира барои кор бе интернет»**
   («Сохранить для работы без интернета»). (Или нажмите **Ctrl+S** и сохраните
   страницу как «Веб-страница, только HTML».)
3. Скопируйте сохранённый файл на флешку.
4. На каждом компьютере класса откройте файл с флешки (или скопировав на рабочий
   стол) в браузере — например, двойным щелчком.

Для этого не нужны права администратора и установка программ.

Песочница проверена в Chromium. В старых браузерах она может не работать; в
таком случае используйте более новый браузер. Если браузер не может выполнить
программу, страница сообщит об этом.

Если установлен Node.js, файл можно собрать и из исходного кода:
`npm run build:playground` (файл появится в `playground/dist/index.html`).

## 2. Уроки и задачи

- 18 уроков от `чоп` до объектов: [оглавление](ru/README.md) (по-таджикски:
  [мундариҷа](tj/README.md)).
- В каждом уроке 2–3 примера; ссылка «▶ Запустить в песочнице» открывает пример
  в песочнице (нужен интернет).
- В каждом уроке 3–4 задачи: [все задачи](tasks/README.md). На странице задачи —
  условие, пример ввода и вывода и ссылка в песочницу.

### Раздача заданий

- **С интернетом:** отправьте ученикам ссылку на задачу или пример. Ученик может
  прислать вам свою программу кнопкой **🔗 Пайванд** («Ссылка»): в ссылке
  записаны программа и её ввод.
- **Без интернета:** все 63 задачи есть в самой песочнице, в списке
  **«Масъала»** («Задача», по урокам). Ученик выбирает задачу: появляются её
  условие, начальная программа и ввод, а кнопка **✓ Санҷидан** проверяет
  программу на всех тестах — и в файле, открытом с флешки. Ученикам достаточно
  назвать номер задачи, например «05-jam».

### Проверка заданий

- **В песочнице:** выберите задачу в списке **«Масъала»** или откройте ссылку
  «▶ Решить в песочнице» на странице задачи. Ученик пишет программу и нажимает
  **✓ Санҷидан** («Проверить»): программа выполняется на каждом тесте, и
  песочница показывает, какие тесты пройдены, а для остальных — что ожидалось и
  что программа вывела. Это работает в браузере, без Node.js; тесты записаны в
  самой ссылке.
- **Вручную:** сравните вывод программы с примером на странице задачи. Проверьте
  и другой ввод: тесты лежат в папке `tests` (`1.in` — ввод, `1.out` — ожидаемый
  вывод).
- **Автоматически:** если на компьютере учителя есть Node.js, скачайте исходный
  код SomonScript с GitHub и один раз выполните `npm install` и `npm run build`.
  После этого программа ученика проверяется на всех тестах так:

  ```bash
  npm run check-task -- 05-jam барнома.som --lang ru
  ```

  Ответ показывает, какие тесты прошли и что программа вывела в остальных.

- Образец решения каждой задачи — в файле `hal.som`.

## 3. Частые ошибки учеников

| Ошибка                                                          | Что говорит песочница                                                     | Что подсказать                                              |
| --------------------------------------------------------------- | ------------------------------------------------------------------------- | ----------------------------------------------------------- |
| Не закрыта кавычка: `чоп("Салом);`                              | Нет закрывающей кавычки `"`                                               | Каждую открытую `"` нужно закрыть.                          |
| Не закрыта скобка                                               | Нет закрывающей `)` (или `}`); строка, где она открыта                    | Считайте скобки парами.                                     |
| Ключевое слово с ошибкой: `агр`, `вагрна`                       | Подсказка: может быть, имелось в виду `агар`?                             | Прочитайте подсказку.                                       |
| Латинская буква в кириллическом слове: `чoп`                    | Имя … не объявлено, подсказка с похожим именем                            | Перепечатайте слово в таджикской раскладке.                 |
| Таджикская буква заменена: `хонданиРакам` вместо `хонданиРақам` | Имя … не объявлено; подсказка: может быть, имелось в виду `хонданиРақам`? | Для ӣ, ҷ, ҳ, қ, ғ, ӯ нужна таджикская раскладка клавиатуры. |
| Переменная не объявлена                                         | Имя `ном` не объявлено                                                    | Сначала `тағ ном = …;`.                                     |
| `хондан()` вместо `хонданиРақам()`                              | Ошибки нет, но `2` и `3` → `23`                                           | Для чисел — `хонданиРақам()`.                               |
| Во вводе не число                                               | `се` — не число: `хонданиРақам()` ждала число                             | Напишите в «Вуруд» число.                                   |
| Мало строк ввода                                                | Ввод закончился                                                           | В «Вуруд» столько строк, сколько читает программа.          |
| `=` в условии: `агар (х = 5)`                                   | Предупреждение: в условии `=` присваивает значение                        | Для сравнения — `===`.                                      |
| Бесконечный цикл                                                | Программа работала слишком долго — может быть, бесконечный цикл?          | Переменная цикла должна меняться.                           |
| Индекс с 1: `рӯйхат[рӯйхат.дарозӣ]`                             | Нельзя прочитать свойство: значение `беқимат`                             | Индекс начинается с 0.                                      |
| Запятая в числе в программе: `2,5`                              | Здесь нужно имя, а написано `5`                                           | В программе `2.5`; во вводе можно и `2,5`.                  |

В сообщении об ошибке всегда есть номер строки, и эта строка выделяется красным
в редакторе. Научите учеников сначала читать сообщение: этому посвящён
[урок 2](ru/02-khato.md).

## 4. Соответствие учебной программе

В школах Таджикистана программирование изучают в предмете «Технологияи
иттилоотӣ» («Информационные технологии»). Ниже уроки SomonScript сравниваются с
учебниками этого предмета, которые утвердило Министерство образования и науки
(издательство «Маориф»). Учебники есть в
[библиотеке на сайте министерства](https://www.maorif.tj/libraries); сравнение
сделано по их оглавлениям в октябре 2026 года. Министерство его не проверяло и
не утверждало: уроки SomonScript — не официальный учебный материал.

### Уроки SomonScript и учебник 10 класса

Уроки SomonScript проходят основные темы глав 1, 2 и 4 учебника, но на другом
языке: вместо Python — SomonScript, ключевые слова которого — таджикские слова.
Сам учебник поясняет слова Python по-таджикски: `if` — «агар», `for` — «барои»,

### Как можно использовать уроки

- **В 10 классе** — как практику к главам 1, 2 и 4: ученик пишет те же программы
  на языке с таджикскими словами, песочница объясняет ошибки по-таджикски и
  работает без интернета и без установки Python. Программу на Python из учебника
  можно переписать на SomonScript: `print` — `чоп`, `input()` — `хондан()`,
  `int(input())` и `float(input())` — `хонданиРақам()`, `if … elif … else` —
  `агар … вагарна агар … вагарна`, `for i in range(1, n + 1)` —
  `барои (тағ и = 1; и <= н; и++)`, `while` — `то`, `and`, `or`, `not` — `&&`,
  `||`, `!`, `x in a` — `а.дорад(х)`, `len(a)` — `а.дарозӣ`, `math.sqrt` —
  `Риёзӣ.дуръшака`.
- **После 5 и 6 классов** — как следующий шаг после алгоритмов и Scratch: те же
  линейные, ветвящиеся и циклические алгоритмы, но в тексте программы.
- **В 7 и 8 классах**, где в учебниках программирования нет, — например, на
  кружке.
