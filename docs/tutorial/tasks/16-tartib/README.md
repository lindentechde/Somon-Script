# Тартиб / Сортировка

## Масъала 16-tartib: Тартиб

Рақамҳоро ба рӯйхат хонед ва онҳоро аз хурд ба калон, ҳар кадом дар сатри
алоҳида, чоп кунед.

**Вуруд:** Сатри аввал — шумораи рақамҳо `н`, баъд `н` сатр, дар ҳар кадом як
рақам.

**Натиҷа:** Рақамҳо аз хурд ба калон.

### Мисол

Вуруд:

```text
4
30
4
100
25
```

Натиҷа:

```text
4
25
30
100
```

```som
// Масъала 16-tartib: Тартиб
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
4
30
4
100
25
```

## Задача 16-tartib: Сортировка

Прочитайте числа в список и выведите их по возрастанию, каждое в отдельной
строке.

**Ввод:** Первая строка — количество чисел `н`, затем `н` строк, в каждой по
числу.

**Вывод:** Числа по возрастанию.

### Пример

Ввод:

```text
4
30
4
100
25
```

Вывод:

```text
4
25
30
100
```

