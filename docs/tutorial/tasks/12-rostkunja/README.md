# Росткунҷа / Прямоугольник

## Масъала 12-rostkunja: Росткунҷа

Баландӣ ва барро хонед ва росткунҷаи аз `*` иборатро чоп кунед.

**Вуруд:** Ду рақам: баландӣ, баъд бар.

**Натиҷа:** Росткунҷа.

### Мисол

Вуруд:

```text
2
3
```

Натиҷа:

```text
***
***
```

```som
// Масъала 12-rostkunja: Росткунҷа
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
2
3
```

## Задача 12-rostkunja: Прямоугольник

Прочитайте высоту и ширину и выведите прямоугольник из `*`.

**Ввод:** Два числа: высота, затем ширина.

**Вывод:** Прямоугольник.

### Пример

Ввод:

```text
2
3
```

Вывод:

```text
***
***
```

```som
// Задача 12-rostkunja: Прямоугольник
// Напишите свою программу здесь
```

Ввод:

```text
2
3
```
