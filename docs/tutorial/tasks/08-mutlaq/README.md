# Қимати мутлақ / Модуль числа

## Масъала 08-mutlaq: Қимати мутлақ

Рақамро хонед ва қимати мутлақи онро чоп кунед, бе `Риёзӣ.мутлақ`: агар рақам
манфӣ бошад, аломаташро иваз кунед.

**Вуруд:** Як рақам.

**Натиҷа:** Қимати мутлақ.

### Мисол

Вуруд:

```text
-7
```

Натиҷа:

```text
7
```

```som
// Масъала 08-mutlaq: Қимати мутлақ
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
-7
```

## Задача 08-mutlaq: Модуль числа

Прочитайте число и выведите его модуль, не используя `Риёзӣ.мутлақ`: если число
отрицательное, смените знак.

**Ввод:** Одно число.

**Вывод:** Модуль.

### Пример

Ввод:

```text
-7
```

Вывод:

```text
7
```

```som
// Задача 08-mutlaq: Модуль числа
// Напишите свою программу здесь
```

Ввод:

```text
-7
```

В песочнице кнопка **✓ Санҷидан** («Проверить») проверяет программу на всех
тестах этой задачи.

### Проверка на компьютере

Если установлены Node.js и SomonScript, программа проверяется на всех тестах:

```bash
npm run check-task -- 08-mutlaq барнома.som
```
