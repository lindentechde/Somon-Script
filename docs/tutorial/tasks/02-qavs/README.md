# Қавс / Скобка

## Масъала 02-qavs: Қавс

Дар ин барнома ду хато бо қавсҳо ҳаст. Онҳоро ислоҳ кунед, то `Як`, `Ду` ва `Се`
дар се сатр чоп шаванд.

**Вуруд:** Нест.

**Натиҷа:** `Як`, `Ду`, `Се`, ҳар кадом дар сатри алоҳида.

### Мисол

Натиҷа:

```text
Як
Ду
Се
```

Барномаи хатодор:

```text
чоп("Як";
чоп("Ду");
чоп("Се"));
```

[▶ Дар майдони озмоиш ҳал кунед](https://lindentechde.github.io/Somon-Script/#c=0YfQvtC_KCLQr9C6IjsK0YfQvtC_KCLQlNGDIik7CtGH0L7Qvygi0KHQtSIpKTsK)

### Санҷиш бо компютер

Агар Node.js ва SomonScript насб бошанд, барномаро бо ҳамаи санҷишҳо месанҷед:

```bash
npm run check-task -- 02-qavs барнома.som
```

## Задача 02-qavs: Скобка

В этой программе две ошибки со скобками. Исправьте их, чтобы `Як`, `Ду` и `Се`
вывелись в трёх строках.

**Ввод:** Нет.

**Вывод:** `Як`, `Ду`, `Се`, каждое в отдельной строке.

### Пример

Вывод:

```text
Як
Ду
Се
```

Программа с ошибкой:

```text
чоп("Як";
чоп("Ду");
чоп("Се"));
```

[▶ Решить в песочнице](https://lindentechde.github.io/Somon-Script/#c=0YfQvtC_KCLQr9C6IjsK0YfQvtC_KCLQlNGDIik7CtGH0L7Qvygi0KHQtSIpKTsK)

### Проверка на компьютере

Если установлены Node.js и SomonScript, программа проверяется на всех тестах:

```bash
npm run check-task -- 02-qavs барнома.som
```
