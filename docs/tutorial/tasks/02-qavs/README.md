## Масъала 02-qavs: Қавс

Дар ин барнома ду хато бо қавсҳо ҳаст. Онҳоро ислоҳ кунед, то `Як`, `Ду` ва `Се`
дар се сатр чоп шаванд.

**Вуруд:** Нест.

**Натиҷа:** `Як`, `Ду`, `Се`, ҳар кадом дар сатри алоҳида.

### Мисол

Натиҷа:

```text
Як
Ду
Се
```

Барномаи хатодор:

```text

чоп("Се"));
```

## Задача 02-qavs: Скобка

В этой программе две ошибки со скобками. Исправьте их, чтобы `Як`, `Ду` и `Се`
вывелись в трёх строках.

**Ввод:** Нет.

**Вывод:** `Як`, `Ду`, `Се`, каждое в отдельной строке.

### Пример

Вывод:

```text
Як
Ду
Се
```

Программа с ошибкой:

```text
чоп("Як";
чоп("Ду");
чоп("Се"));
```

## Task 02-qavs: The bracket

This program has two mistakes with brackets. Fix them so that `Як`, `Ду` and
`Се` are printed on three lines.

**Input:** None.

**Output:** `Як`, `Ду`, `Се`, each on its own line.

### Example

Output:

```text
Як
Ду
Се
```

The broken program:

```text
чоп("Як";
чоп("Ду");
чоп("Се"));
```
