# Ҷамъи рақамҳо / Сумма цифр

## Масъала 06-jami-raqamho: Ҷамъи рақамҳо

Адади сеҳонаро хонед ва ҷамъи рақамҳои онро чоп кунед. Масалан, барои `123`
ҷавоб `6` аст. Маслиҳат: `% 10` рақами охиринро медиҳад.

**Вуруд:** Адади сеҳона.

**Натиҷа:** Ҷамъи рақамҳо.

### Мисол

Вуруд:

```text
123
```

Натиҷа:

```text
6
```

```som
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
123
```

## Задача 06-jami-raqamho: Сумма цифр

Прочитайте трёхзначное число и выведите сумму его цифр. Например, для `123`
ответ `6`. Подсказка: `% 10` даёт последнюю цифру.

**Ввод:** Трёхзначное число.

**Вывод:** Сумма цифр.

### Пример

Ввод:

```text
123
```

Вывод:

```text
6
```
