## Масъала 06-soat: Соат ва дақиқа

Шумораи дақиқаҳоро хонед ва онро ба соат ва дақиқа табдил диҳед:
`2 соат 15 дақиқа`.

**Вуруд:** Як рақам: дақиқаҳо.

**Натиҷа:** `Н соат М дақиқа`
