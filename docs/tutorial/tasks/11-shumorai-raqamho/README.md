## Задача 11-shumorai-raqamho: Количество цифр

Прочитайте целое положительное число и выведите, сколько в нём цифр.

**Ввод:** Одно положительное число.

**Вывод:** Количество цифр.

### Пример

Ввод:

```text
2026
```

```text
4
```
