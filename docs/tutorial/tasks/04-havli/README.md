# Ҳавлӣ / Двор

## Масъала 04-havli: Ҳавлӣ

Ҳавлӣ 12 метр тӯл ва 7 метр бар дорад. Масоҳат ва периметри онро ҳисоб кунед ва
чоп кунед: `Масоҳат: …` ва `Периметр: …`.

**Вуруд:** Нест.

**Натиҷа:** Ду сатр: масоҳат ва периметр.

### Мисол

Натиҷа:

```text
Масоҳат: 84
Периметр: 38
```

```som
// Масъала 04-havli: Ҳавлӣ
// Барномаи худро ин ҷо нависед
```

### Санҷиш бо компютер

Агар Node.js ва SomonScript насб бошанд, барномаро бо ҳамаи санҷишҳо месанҷед:

```bash
npm run check-task -- 04-havli барнома.som
```

## Задача 04-havli: Двор

Двор имеет длину 12 метров и ширину 7 метров. Вычислите его площадь и периметр и
выведите: `Масоҳат: …` и `Периметр: …`.

**Ввод:** Нет.

**Вывод:** Две строки: площадь и периметр.

### Пример

Вывод:

```text
Масоҳат: 84
Периметр: 38
```

```som
// Задача 04-havli: Двор
// Напишите свою программу здесь
```

[▶ Решить в песочнице](https://lindentechde.github.io/Somon-Script/#c=Ly8g0JfQsNC00LDRh9CwIDA0LWhhdmxpOiDQlNCy0L7RgAovLyDQndCw0L_QuNGI0LjRgtC1INGB0LLQvtGOINC_0YDQvtCz0YDQsNC80LzRgyDQt9C00LXRgdGMCg&t=W3siaSI6IiIsIm8iOiLQnNCw0YHQvtKz0LDRgjogODRcbtCf0LXRgNC40LzQtdGC0YA6IDM4XG4ifV0)

В песочнице кнопка **✓ Санҷидан** («Проверить») проверяет программу на всех
тестах этой задачи.

### Проверка на компьютере

Если установлены Node.js и SomonScript, программа проверяется на всех тестах:

```bash
npm run check-task -- 04-havli барнома.som
```
