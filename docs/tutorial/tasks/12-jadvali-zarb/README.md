# Ҷадвали зарби пурра / Полная таблица умножения

## Масъала 12-jadvali-zarb: Ҷадвали зарби пурра

Рақами `н`-ро хонед ва ҷадвали зарби `н × н`-ро чоп кунед: дар сатри `и`
ҳосилҳои `и × 1` то `и × н`, бо фосила ҷудо.

**Вуруд:** Як рақам: `н`.

**Натиҷа:** `н` сатр.

### Мисол

Вуруд:

```text
3
```

Натиҷа:

```text
1 2 3
2 4 6
3 6 9
```

```som
// Масъала 12-jadvali-zarb: Ҷадвали зарби пурра
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
3
```

## Задача 12-jadvali-zarb: Полная таблица умножения

Прочитайте число `н` и выведите таблицу умножения `н × н`: в строке `и`
произведения от `и × 1` до `и × н` через пробел.

**Ввод:** Одно число: `н`.

**Вывод:** `н` строк.

### Пример

Ввод:

```text
3
```

Вывод:

```text
1 2 3
2 4 6
3 6 9
```

```som
// Задача 12-jadvali-zarb: Полная таблица умножения
// Напишите свою программу здесь
```

Ввод:

```text
3
```
