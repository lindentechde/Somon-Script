# Беҳтарин / Лучший

## Масъала 18-behtarin: Беҳтарин

Шумораи хонандагон `н`-ро хонед, баъд барои ҳар кадом ном ва холро. Ном ва холи
хонандаи беҳтаринро чоп кунед (агар якчанд бошад, аввалинашро).

**Вуруд:** `н`, баъд барои ҳар хонанда ду сатр: ном ва хол.

**Натиҷа:** `ном хол`

### Мисол

Вуруд:

```text
3
Алӣ
78
Зарина
95
Фарҳод
88
```

Натиҷа:

```text
Зарина 95
```

```som
// Масъала 18-behtarin: Беҳтарин
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text

88
```

## Задача 18-behtarin: Лучший

Прочитайте количество учеников `н`, затем для каждого имя и балл. Выведите имя и
балл лучшего ученика (если таких несколько — первого).

**Ввод:** `н`, затем для каждого ученика две строки: имя и балл.

**Вывод:** `имя балл`

### Пример

Ввод:

```text
3
Алӣ
78
Зарина
95
Фарҳод
88
```

Вывод:

```text
Зарина 95
```
