## Масъала 18-behtarin: Беҳтарин

Шумораи хонандагон `н`-ро хонед, баъд барои ҳар кадом ном ва холро. Ном ва холи
хонандаи беҳтаринро чоп кунед (агар якчанд бошад, аввалинашро).

**Вуруд:** `н`, баъд барои ҳар хонанда ду сатр: ном ва хол.

**Натиҷа:** `ном хол`

### Мисол

```text

95
Фарҳод
88
```

## Task 18-behtarin: The best

Read the number of students `н`, then a name and a score for each of them. Print
the name and the score of the best student (if there are several, the first of
them).

**Input:** `н`, then two lines for each student: the name and the score.

**Output:** `name score`

### Example

Input:

```text
3
Алӣ
78
Зарина
95
Фарҳод
88
```

Output:

```text
Зарина 95
```
