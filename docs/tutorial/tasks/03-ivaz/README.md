## Масъала 03-ivaz: Иваз

Барнома бо `тағ а = 5;` ва `тағ б = 8;` сар мешавад. Қиматҳои `а` ва `б`-ро иваз
кунед - бе он ки рақамҳои 5 ва 8-ро боз нависед - ва `а = 8` ва `б = 5`-ро чоп
кунед. Маслиҳат: тағйирёбандаи сеюм лозим мешавад.

**Вуруд:** Нест.

**Натиҷа:** `а = 8` ва `б = 5`.

and `б` - without writing the numbers 5 and 8 again - and print `а = 8` and
`б = 5`. Hint: you will need a third variable.

**Input:** None.

**Output:** `а = 8` and `б = 5`.
