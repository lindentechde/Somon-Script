# Ҳарфи «а» / Буква «а»

## Масъала 17-harfi-a: Ҳарфи «а»

Сатрро хонед ва чоп кунед, ки ҳарфи хурди `а` дар он чанд бор омадааст.

**Вуруд:** Як сатр.

**Натиҷа:** Шумора.

### Мисол

Вуруд:

```text
барномасозӣ
```

Натиҷа:

```text
2
```

```som
// Масъала 17-harfi-a: Ҳарфи «а»
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
барномасозӣ
```

## Задача 17-harfi-a: Буква «а»

Прочитайте строку и выведите, сколько раз в ней встречается строчная буква `а`.

**Ввод:** Одна строка.

**Вывод:** Количество.

### Пример

Ввод:

```text
барномасозӣ
```

Вывод:

```text
2
```
