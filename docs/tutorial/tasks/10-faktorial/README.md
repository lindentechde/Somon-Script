## Масъала 10-faktorial: Факториал

Рақами `н`-ро хонед ва факториали онро чоп кунед: `1 × 2 × … × н`. Факториали
`0` ба `1` баробар аст.

**Вуруд:** Як рақам: `н`.

**Натиҷа:** Факториал.

### Мисол

Вуруд:

```text
5
```

Натиҷа:

```text
120
```

```som
// Масъала 10-faktorial: Факториал
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
5
```
