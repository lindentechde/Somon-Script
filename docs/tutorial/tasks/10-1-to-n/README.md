# Аз 1 то н / От 1 до н

## Масъала 10-1-to-n: Аз 1 то н

Рақами `н`-ро хонед ва рақамҳои 1 то `н`-ро, ҳар кадом дар сатри алоҳида, чоп
кунед.

**Вуруд:** Як рақам: `н`.

**Натиҷа:** Рақамҳои 1 то `н`.

### Мисол

Вуруд:

```text
3
```

Натиҷа:

```text
1
2
3
```

```som
// Масъала 10-1-to-n: Аз 1 то н
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
3
```

## Задача 10-1-to-n: От 1 до н

Прочитайте число `н` и выведите числа от 1 до `н`, каждое в отдельной строке.

**Ввод:** Одно число: `н`.

**Вывод:** Числа от 1 до `н`.

### Пример

Ввод:

```text
3
```

Вывод:

```text
1
2
3
```

```som
// Задача 10-1-to-n: От 1 до н
// Напишите свою программу здесь
```

Ввод:

```text
3
```

тестах этой задачи.

### Проверка на компьютере

Если установлены Node.js и SomonScript, программа проверяется на всех тестах:

```bash
npm run check-task -- 10-1-to-n барнома.som
```
