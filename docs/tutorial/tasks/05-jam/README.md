# Ҷамъ / Сумма

## Масъала 05-jam: Ҷамъ

Ду рақамро хонед ва ҷамъи онҳоро чоп кунед.

**Вуруд:** Ду сатр, дар ҳар кадом як рақам.

**Натиҷа:** Як рақам — ҷамъ.

### Мисол

Вуруд:

```text
2
3
```

Натиҷа:

```text
5
```

```som

// Барномаи худро ин ҷо нависед
```

```text

3
```

## Задача 05-jam: Сумма

Прочитайте два числа и выведите их сумму.

**Ввод:** Две строки, в каждой число.

**Вывод:** Одно число — сумма.

### Пример

Ввод:

```text
2
3
```

Вывод:

```text
5
```

```som
// Напишите свою программу здесь
```

Ввод:

```text

```
