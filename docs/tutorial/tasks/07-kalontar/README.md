# Калонтар? / Больше?

## Масъала 07-kalontar: Калонтар?

Ду рақамро хонед ва натиҷаи муқоисаи `а > б`-ро чоп кунед: `дуруст` ё
`нодуруст`.

**Вуруд:** Ду рақам.

**Натиҷа:** `дуруст` ё `нодуруст`

### Мисол

Вуруд:

```text
5
3
```

Натиҷа:

```text
дуруст
```

```som
// Масъала 07-kalontar: Калонтар?
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
5
3
```
