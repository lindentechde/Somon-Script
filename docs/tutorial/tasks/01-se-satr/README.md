## Масъала 01-se-satr: Се сатр

Ин се сатрро айнан чоп кунед:

```text

Барнома аз фармонҳо иборат аст.
Ҳар фармон бо нуқтавергул тамом мешавад.
```

**Вуруд:** Нест.

**Натиҷа:** Се сатри боло.
