# Адади содда / Простое число

## Масъала 14-sodda: Адади содда

Функсияи `соддаАст(н)`-ро нависед, ки `дуруст` бармегардонад, агар `н` адади
содда бошад (аз 1 калон ва танҳо ба 1 ва худаш тақсим мешавад). Рақамро хонед ва
`Содда` ё `Содда нест` чоп кунед.

**Вуруд:** Як рақами бутун.

**Натиҷа:** `Содда` ё `Содда нест`

### Мисол

Вуруд:

```text
7
```

Натиҷа:

```text
Содда
```

```som
// Масъала 14-sodda: Адади содда
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
7
```

## Задача 14-sodda: Простое число

Напишите функцию `соддаАст(н)`, которая возвращает `дуруст`, если `н` — простое
число (больше 1 и делится только на 1 и на себя). Прочитайте число и выведите
`Содда` или `Содда нест`.

**Ввод:** Одно целое число.

**Вывод:** `Содда` или `Содда нест`

### Пример

Ввод:

```text
7
```

Вывод:

```text
Содда
```

```som
// Задача 14-sodda: Простое число
// Напишите свою программу здесь
```

Ввод:

```text
7
```
