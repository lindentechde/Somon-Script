# Масъалаҳо / Задачи / Tasks

Ҳар масъала санҷишҳо дорад: вуруд (`tests/1.in`) ва натиҷаи интизорӣ
(`tests/1.out`). Ҳалли намунавӣ - `hal.som` (барои омӯзгор).

У каждой задачи есть тесты: ввод (`tests/1.in`) и ожидаемый вывод
(`tests/1.out`). Образец решения - `hal.som` (для учителя).

Each task has tests: the input (`tests/1.in`) and the expected output
(`tests/1.out`). A model solution is in `hal.som` (for the teacher).

```bash
npm run check-task -- 05-jam барнома.som
```

Ҳамаи масъалаҳо дар майдони озмоиш, дар рӯйхати «Масъала», бе интернет ҳам
ҳастанд. / Все задачи есть в песочнице, в списке «Масъала», и без интернета.

Пайванди «▶» дар саҳифаи масъала майдони озмоишро бо санҷишҳои масъала
мекушояд: тугмаи **✓ Санҷидан** барномаро бо ҳамаи онҳо месанҷад, бе Node.js. /
Ссылка «▶» на странице задачи открывает песочницу с тестами задачи: кнопка **✓
Санҷидан** («Проверить») проверяет программу на всех тестах, без Node.js.
