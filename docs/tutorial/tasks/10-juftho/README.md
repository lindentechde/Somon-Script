# Ҷуфтҳо / Чётные

## Масъала 10-juftho: Ҷуфтҳо

Рақами `н`-ро хонед ва ҳамаи рақамҳои ҷуфтро аз 2 то `н`, ҳар кадом дар сатри
алоҳида, чоп кунед.

**Вуруд:** Як рақам: `н`.

**Натиҷа:** Рақамҳои ҷуфт.

### Мисол

Вуруд:

```text
7
```

Натиҷа:

```text
2
4
6
```

```som
// Масъала 10-juftho: Ҷуфтҳо
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
7
```

## Задача 10-juftho: Чётные

Прочитайте число `н` и выведите все чётные числа от 2 до `н`, каждое в отдельной
строке.

**Ввод:** Одно число: `н`.

**Вывод:** Чётные числа.

### Пример

Ввод:

```text
7
```

Вывод:

```text
2
4
6
```

```som
// Задача 10-juftho: Чётные
// Напишите свою программу здесь
```

Ввод:

```text
7
```
