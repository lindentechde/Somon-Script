# Секунҷаи рақамҳо / Треугольник из цифр

## Масъала 12-sekunjai-raqamho: Секунҷаи рақамҳо

Рақами `н`-ро хонед ва `н` сатр чоп кунед: дар сатри якум `1`, дар дуюм `12`,
дар сеюм `123` ва ҳоказо.

**Вуруд:** Як рақам: `н` (1 то 9).

**Натиҷа:** `н` сатр.

### Мисол

Вуруд:

```text
3
```

Натиҷа:

```text
1
12
123
```

```som
// Масъала 12-sekunjai-raqamho: Секунҷаи рақамҳо
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
3
```

## Задача 12-sekunjai-raqamho: Треугольник из цифр

третьей `123` и так далее.

**Ввод:** Одно число: `н` (от 1 до 9).

**Вывод:** `н` строк.

### Пример

Ввод:

```text
3
```
