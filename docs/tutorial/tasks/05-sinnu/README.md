Соли таваллуд ва соли ҷориро хонед ва чоп кунед, ки одам имсол чандсола мешавад.

**Вуруд:** Ду сатр: соли таваллуд, баъд соли ҷорӣ.

**Натиҷа:** Як рақам.

### Мисол

```text

2026
```

```text
14
```

## Задача 05-sinnu: Возраст

Прочитайте год рождения и текущий год и выведите, сколько человеку исполняется в
этом году.

**Ввод:** Две строки: год рождения, затем текущий год.

**Вывод:** Одно число.

```text
2012
2026
```
