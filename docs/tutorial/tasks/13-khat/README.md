# Хат / Линия

## Масъала 13-khat: Хат

Функсияи `хат(н)`-ро нависед, ки `н` аломати `=`-ро дар як сатр чоп кунад.
Рақамро хонед ва функсияро даъват кунед.

**Вуруд:** Як рақам.

**Натиҷа:** Як сатр аз `=`.

### Мисол

Вуруд:

```text
5
```

Натиҷа:

```text
=====
```

```som
// Масъала 13-khat: Хат
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
5
```

## Задача 13-khat: Линия

Напишите функцию `хат(н)`, которая выводит в одной строке `н` знаков `=`.
Прочитайте число и вызовите функцию.

**Ввод:** Одно число.

**Вывод:** Одна строка из `=`.

### Пример

Ввод:

```text
5
```

Вывод:

```text
=====
```

```som
// Задача 13-khat: Линия
// Напишите свою программу здесь
```

Ввод:

```text
5
```
