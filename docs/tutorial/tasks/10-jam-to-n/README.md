# Ҷамъ аз 1 то н / Сумма от 1 до н

## Масъала 10-jam-to-n: Ҷамъ аз 1 то н

Рақами `н`-ро хонед ва ҷамъи ҳамаи рақамҳои 1 то `н`-ро чоп кунед.

**Вуруд:** Як рақам: `н`.

**Натиҷа:** Ҷамъ.

### Мисол

Вуруд:

```text
10
```

Натиҷа:

```text
55
```

```som

// Барномаи худро ин ҷо нависед
```

Вуруд:

```text

```
