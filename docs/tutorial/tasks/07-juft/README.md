# Ҷуфт? / Чётное?

## Масъала 07-juft: Ҷуфт?

Рақамро хонед ва чоп кунед, ки оё он ҷуфт аст: `дуруст` ё `нодуруст`.

**Вуруд:** Як рақам.

**Натиҷа:** `дуруст` ё `нодуруст`

### Мисол

Вуруд:

```text
10
```

Натиҷа:

```text
дуруст
```

```som
// Масъала 07-juft: Ҷуфт?
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
10
```
