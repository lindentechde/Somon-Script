# Палиндром / Палиндром

## Масъала 17-palindrom: Палиндром

Калимаро хонед. Агар он аз охир ҳамон тавр хонда шавад (масалан, `нон`), `Ҳа`,
вагарна `Не` чоп кунед.

**Вуруд:** Як калима.

**Натиҷа:** `Ҳа` ё `Не`

### Мисол

Вуруд:

```text
нон
```

Натиҷа:

```text
Ҳа
```

```som
// Масъала 17-palindrom: Палиндром
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
нон
```

## Задача 17-palindrom: Палиндром

Прочитайте слово. Если оно читается с конца так же (например, `нон`), выведите
`Ҳа`, иначе `Не`.

**Ввод:** Одно слово.

**Вывод:** `Ҳа` или `Не`

### Пример

Ввод:

```text
нон
```

Вывод:

```text
Ҳа
```

```som

// Напишите свою программу здесь
```

Ввод:

```text
нон
```
