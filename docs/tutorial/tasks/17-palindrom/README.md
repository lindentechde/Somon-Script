## Task 17-palindrom: Palindrome

Read a word. If it reads the same from the end (for example, `нон`, "bread"),
print `Ҳа` ("Yes"), otherwise `Не` ("No").

**Input:** One word.

**Output:** `Ҳа` or `Не`

### Example

Input:

```text
нон
```

Output:

```text
Ҳа
```
