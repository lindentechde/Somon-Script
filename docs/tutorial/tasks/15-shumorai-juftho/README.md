# Шумораи ҷуфтҳо / Количество чётных

## Масъала 15-shumorai-juftho: Шумораи ҷуфтҳо

Рақамҳоро ба рӯйхат хонед ва чоп кунед, ки чандтоашон ҷуфтанд.

**Вуруд:** Сатри аввал — шумораи рақамҳо `н`, баъд `н` сатр, дар ҳар кадом як
рақам.

**Натиҷа:** Шумораи рақамҳои ҷуфт.

**Ввод:** Первая строка — количество чисел `н`, затем `н` строк, в каждой по
числу.
