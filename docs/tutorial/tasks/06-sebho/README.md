# Тақсими себҳо / Делим яблоки

## Масъала 06-sebho: Тақсими себҳо

Шумораи себҳо ва шумораи кӯдаконро хонед. Себҳо баробар тақсим мешаванд. Чоп
кунед, ки ба ҳар кас чанд себ мерасад ва чандто боқӣ мемонад.

**Вуруд:** Ду сатр: себҳо, баъд кӯдакон.

**Натиҷа:** `Ҳар кас: …` ва `Боқӣ: …`

### Мисол

Вуруд:

```text
17
5
```

Натиҷа:

```text
Ҳар кас: 3
Боқӣ: 2
```

```som
// Масъала 06-sebho: Тақсими себҳо
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
17
5
```

## Задача 06-sebho: Делим яблоки

Прочитайте число яблок и число детей. Яблоки делят поровну. Выведите, сколько
яблок достанется каждому и сколько останется.

**Ввод:** Две строки: яблоки, затем дети.

**Вывод:** `Ҳар кас: …` и `Боқӣ: …`

### Пример

Ввод:

```text
17
5
```

Вывод:

```text
Ҳар кас: 3
Боқӣ: 2
```
