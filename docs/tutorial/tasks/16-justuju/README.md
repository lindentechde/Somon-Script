# Ҷустуҷӯ / Поиск

## Масъала 16-justuju: Ҷустуҷӯ

Рақамҳоро ба рӯйхат хонед, баъд рақами ҷустуҷӯро. Индекси аввалини онро дар
рӯйхат чоп кунед, ё `-1`, агар он набошад.

**Вуруд:** Сатри аввал — `н`, баъд `н` рақам, баъд рақами ҷустуҷӯ.

**Натиҷа:** Индекс ё `-1`.

### Мисол

Вуруд:

```text
4
5
8
2
8
8
```

Натиҷа:

```text
1
```

```som
// Масъала 16-justuju: Ҷустуҷӯ
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
4
5
8
2
8
8
```

## Задача 16-justuju: Поиск

Прочитайте числа в список, затем искомое число. Выведите его первый индекс в
списке или `-1`, если его нет.

**Ввод:** Первая строка — `н`, затем `н` чисел, затем искомое число.

**Вывод:** Индекс или `-1`.

### Пример

Ввод:

```text
4
5
8
2
8
8
```

Вывод:

```text
1
```

```som
// Задача 16-justuju: Поиск
// Напишите свою программу здесь
```

Ввод:

```text
4
5
8
2
8
8
```

Если установлены Node.js и SomonScript, программа проверяется на всех тестах:

```bash

```
