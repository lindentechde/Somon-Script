## Масъала 05-kvadrat: Квадрат

Рақамро хонед ва квадрати онро (рақамро зарб дар худаш) чоп кунед.

**Вуруд:** Як рақам.

**Натиҷа:** Квадрати он.

### Мисол

Вуруд:

```text
4
```

Натиҷа:

```text
16
```

```som
// Масъала 05-kvadrat: Квадрат
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
4
```

## Задача 05-kvadrat: Квадрат

Прочитайте число и выведите его квадрат (число, умноженное само на себя).

**Ввод:** Одно число.

**Вывод:** Его квадрат.

### Пример

Ввод:

```text
4
```

Вывод:

```text
16
```

```som

// Напишите свою программу здесь
```

Ввод:

```text
4
```
