# Хонанда / Ученик

## Масъала 18-khonanda: Хонанда

Ном ва се холи хонандаро хонед. Объекти `{ ном, холҳо }` созед ва `ном: миёна`
чоп кунед, ки миёна — миёнаи се хол аст.

**Вуруд:** Чор сатр: ном, баъд се хол.

**Натиҷа:** `ном: миёна`

### Мисол

Вуруд:

```text
Зарина
5
4
3
```

Натиҷа:

```text
Зарина: 4
```

```som
// Масъала 18-khonanda: Хонанда
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text

5
4
3
```

## Задача 18-khonanda: Ученик

Прочитайте имя и три оценки ученика. Создайте объект `{ ном, холҳо }` и выведите
`имя: среднее`, где среднее — среднее трёх оценок.

**Ввод:** Четыре строки: имя, затем три оценки.

**Вывод:** `имя: среднее`

### Пример

Ввод:

```text
Зарина
5
4
3
```

Вывод:

```text
Зарина: 4
```
