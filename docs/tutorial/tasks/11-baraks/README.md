## Масъала 11-baraks: Баръакс

Адади мусбати бутунро хонед ва рақамҳои онро баръакс чоп кунед: аз `123` -
`321`, аз `1200` - `21`.

**Вуруд:** Як адади мусбат.

**Натиҷа:** Адади баръакс.

### Мисол

Вуруд:

```text
123
```

Натиҷа:

```text
321
```

```som

// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
123
```

`123` - `321`, из `1200` - `21`.

**Ввод:** Одно положительное число.

**Вывод:** Перевёрнутое число.

## Task 11-baraks: Backwards

you get `321`, from `1200` you get `21`.

**Input:** One positive number.

**Output:** The reversed number.

### Example

Input:

```text
123
```

Output:

```text
321
```
