# Баръакс / Наоборот

## Масъала 11-baraks: Баръакс

Адади мусбати бутунро хонед ва рақамҳои онро баръакс чоп кунед: аз `123` —
`321`, аз `1200` — `21`.

**Вуруд:** Як адади мусбат.

**Натиҷа:** Адади баръакс.

### Мисол

Вуруд:

```text
123
```

Натиҷа:

```text
321
```

```som
// Масъала 11-baraks: Баръакс
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
123
```

## Задача 11-baraks: Наоборот

Прочитайте целое положительное число и выведите его цифры в обратном порядке: из
`123` — `321`, из `1200` — `21`.

**Ввод:** Одно положительное число.

**Вывод:** Перевёрнутое число.

### Пример

Ввод:

```text
123
```

Вывод:

```text
321
```

```som
// Задача 11-baraks: Наоборот
// Напишите свою программу здесь
```

Ввод:

```text
123
```
