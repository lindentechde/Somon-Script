# Аз миёна калонтар / Больше среднего

## Масъала 16-az-miyona-kalon: Аз миёна калонтар

Рақамҳоро ба рӯйхат хонед, миёнаи онҳоро ҳисоб кунед ва рақамҳои аз миёна
калонтарро бо ҳамон тартиб, ҳар кадом дар сатри алоҳида, чоп кунед.

**Вуруд:** Сатри аввал — шумораи рақамҳо `н`, баъд `н` сатр, дар ҳар кадом як
рақам.

**Натиҷа:** Рақамҳои аз миёна калонтар.

### Мисол

```text
5
1
2
3
4
5
```

```text
5
```

```som
// Барномаи худро ин ҷо нависед
```

## Задача 16-az-miyona-kalon: Больше среднего

Прочитайте числа в список, найдите их среднее и выведите числа больше среднего в
том же порядке, каждое в отдельной строке.

**Ввод:** Первая строка — количество чисел `н`, затем `н` строк, в каждой по
числу.

**Вывод:** Числа больше среднего.

```text
2

4
5
```
