# Дараҷа / Степень

## Масъала 14-daraja: Дараҷа

Функсияи `дараҷа(асос, нишондиҳанда)`-ро бо давра нависед (бе `Риёзӣ.қувват` ва
`**`). Ду рақамро хонед ва натиҷаро чоп кунед.

**Вуруд:** Ду рақам: асос, баъд нишондиҳанда (0 ё зиёда).

**Натиҷа:** Дараҷа.

### Мисол

Вуруд:

```text
2
10
```

Натиҷа:

```text
1024
```

```som
// Масъала 14-daraja: Дараҷа
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
2
10
```

Напишите функцию `дараҷа(асос, нишондиҳанда)` с циклом (без `Риёзӣ.қувват` и
`**`). Прочитайте два числа и выведите результат.

**Ввод:** Два числа: основание, затем показатель (0 или больше).

**Вывод:** Степень.

### Пример

Ввод:

```text
2
10
```
