# Ҳароратҳо / Температура

## Масъала 14-harorat: Ҳароратҳо

Функсияи `фаренгейт(с)`-ро нависед, ки ҳароратро аз градуси Селсий ба Фаренгейт
табдил дода, бармегардонад: `с * 9 / 5 + 32`. Ҳароратро хонед ва натиҷаро чоп
кунед.

**Вуруд:** Як рақам: градуси Селсий.

**Натиҷа:** Градуси Фаренгейт.

### Мисол

Вуруд:

```text
100
```

Натиҷа:

```text
212
```

```som
// Масъала 14-harorat: Ҳароратҳо
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
100
```

## Задача 14-harorat: Температура

Напишите функцию `фаренгейт(с)`, которая переводит температуру из градусов
Цельсия в Фаренгейты и возвращает её: `с * 9 / 5 + 32`. Прочитайте температуру и
выведите результат.

**Ввод:** Одно число: градусы Цельсия.

**Вывод:** Градусы Фаренгейта.

### Пример

Ввод:

```text
100
```

Вывод:

```text
212
```

```som
// Задача 14-harorat: Температура
// Напишите свою программу здесь
```

Ввод:

```text
100
```
