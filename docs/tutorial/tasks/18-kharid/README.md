# Харид / Покупки

## Масъала 18-kharid: Харид

Шумораи молҳо `н`-ро хонед, баъд барои ҳар мол ном ва нархашро. Ҳамаи молҳоро
ҳамчун объектҳо дар рӯйхат нигоҳ доред. Нархи умумӣ ва номи моли гаронтаринро
чоп кунед.

**Вуруд:** `н`, баъд барои ҳар мол ду сатр: ном ва нарх.

**Натиҷа:** `Ҳамагӣ: …` ва `Гаронтарин: …`

### Мисол

Вуруд:

```text
3
нон
3
шир
8
чой
15
```

Натиҷа:

```text
Ҳамагӣ: 26
Гаронтарин: чой
```

```som
// Масъала 18-kharid: Харид
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text

```

## Задача 18-kharid: Покупки

Прочитайте количество товаров `н`, затем для каждого товара название и цену.
Храните товары как объекты в списке. Выведите общую стоимость и название самого
дорогого товара.

**Ввод:** `н`, затем для каждого товара две строки: название и цена.

**Вывод:** `Ҳамагӣ: …` и `Гаронтарин: …`

### Пример

Ввод:

```text
3
нон
3
шир
8
чой
15
```

Вывод:

```text
Ҳамагӣ: 26
Гаронтарин: чой
```

```som
// Задача 18-kharid: Покупки
// Напишите свою программу здесь
```

Ввод:

```text
3
нон
3
шир
8
чой
15
```
