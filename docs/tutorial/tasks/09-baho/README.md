# Баҳо / Оценка

## Масъала 09-baho: Баҳо

Холро (0 то 100) хонед ва баҳоро чоп кунед: 90 ва зиёда — `5`, 70 ва зиёда —
`4`, 50 ва зиёда — `3`, камтар — `2`.

**Вуруд:** Як рақам: хол.

**Натиҷа:** Баҳо.

### Мисол

Вуруд:

```text
95
```

Натиҷа:

```text
5
```

```som
// Масъала 09-baho: Баҳо
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
95
```

## Задача 09-baho: Оценка

Прочитайте балл (от 0 до 100) и выведите оценку: 90 и больше — `5`, 70 и больше
— `4`, 50 и больше — `3`, меньше — `2`.

**Ввод:** Одно число: балл.

**Вывод:** Оценка.

### Пример

Ввод:

```text
95
```

Вывод:

```text
5
```

```som

```

