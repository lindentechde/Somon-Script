# Сонияҳои рӯз / Секунды в сутках

## Масъала 04-soniyaho: Сонияҳои рӯз

Дар як рӯз 24 соат, дар як соат 60 дақиқа, дар як дақиқа 60 сония ҳаст. Шумораи
сонияҳои як рӯзро бо амалҳо ҳисоб карда, чоп кунед.

**Вуруд:** Нест.

**Натиҷа:** Як рақам.

### Мисол

Натиҷа:

```text
86400
```

```som
// Масъала 04-soniyaho: Сонияҳои рӯз
// Барномаи худро ин ҷо нависед
```

## Задача 04-soniyaho: Секунды в сутках

В сутках 24 часа, в часе 60 минут, в минуте 60 секунд. Вычислите число секунд в
сутках с помощью арифметики и выведите его.

**Ввод:** Нет.

**Вывод:** Одно число.

### Пример

Вывод:

```text
86400
```
