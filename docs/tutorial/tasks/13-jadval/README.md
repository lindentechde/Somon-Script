# Ҷадвал / Таблица

## Масъала 13-jadval: Ҷадвал

Функсияи `ҷадвал(н)`-ро нависед, ки сатрҳои `н × 1 = …` то `н × 5 = …`-ро чоп
кунад. Рақамро хонед ва функсияро даъват кунед.

**Вуруд:** Як рақам.

**Натиҷа:** Панҷ сатр.

### Мисол

Вуруд:

```text
3
```

Натиҷа:

```text
3 × 1 = 3
3 × 2 = 6
3 × 3 = 9
3 × 4 = 12
3 × 5 = 15
```

```som
// Масъала 13-jadval: Ҷадвал
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
3
```

## Задача 13-jadval: Таблица

Напишите функцию `ҷадвал(н)`, которая выводит строки от `н × 1 = …` до
`н × 5 = …`. Прочитайте число и вызовите функцию.

**Ввод:** Одно число.

**Вывод:** Пять строк.

### Пример

Ввод:

```text
3
```

Вывод:

```text
3 × 1 = 3
3 × 2 = 6
3 × 3 = 9
3 × 4 = 12
3 × 5 = 15
```
