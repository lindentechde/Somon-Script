# Хона / Домик

## Масъала 01-khona: Хона

Бо `чоп` ин расмро кашед. Фосилаҳои аввали сатрҳо ҳам муҳиманд.

```text
    *
   ***
  *****
 *******
  |   |
  |___|
```

**Вуруд:** Нест.

**Натиҷа:** Расми боло.

### Мисол

Натиҷа:

```text
    *
   ***
  *****
 *******
  |   |
  |___|
```
