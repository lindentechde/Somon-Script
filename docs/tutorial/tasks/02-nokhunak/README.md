# Нохунак / Кавычка

## Масъала 02-nokhunak: Нохунак

Дар ин барнома хато ҳаст. Онро ислоҳ кунед, то ду сатр чоп шавад.

**Вуруд:** Нест.

**Натиҷа:** `Салом, дӯстон!` ва `Ман хатоҳоро ислоҳ мекунам.` дар ду сатр.

### Мисол

Натиҷа:

```text
Салом, дӯстон!
Ман хатоҳоро ислоҳ мекунам.
```

Барномаи хатодор:

```text
чоп("Салом, дӯстон!);
чоп("Ман хатоҳоро ислоҳ мекунам.");
```

## Задача 02-nokhunak: Кавычка

В этой программе ошибка. Исправьте её, чтобы вывелись две строки.

**Ввод:** Нет.

**Вывод:** `Салом, дӯстон!` и `Ман хатоҳоро ислоҳ мекунам.` в двух строках.

### Пример

Вывод:

```text
Салом, дӯстон!
Ман хатоҳоро ислоҳ мекунам.
```

Программа с ошибкой:

```text
чоп("Салом, дӯстон!);
чоп("Ман хатоҳоро ислоҳ мекунам.");
```
