# Ҷамъи рӯйхат / Сумма списка

## Масъала 15-jami-ruykhat: Ҷамъи рӯйхат

Рақамҳоро ба рӯйхат хонед ва ҷамъи онҳоро чоп кунед.

**Вуруд:** Сатри аввал — шумораи рақамҳо `н`, баъд `н` сатр, дар ҳар кадом як
рақам.

**Натиҷа:** Ҷамъ.

### Мисол

Вуруд:

```text
3
1
2
3
```

Натиҷа:

```text
6
```

```som
// Масъала 15-jami-ruykhat: Ҷамъи рӯйхат
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
3
1
2
3
```

## Задача 15-jami-ruykhat: Сумма списка

Прочитайте числа в список и выведите их сумму.

**Ввод:** Первая строка — количество чисел `н`, затем `н` строк, в каждой по
числу.

**Вывод:** Сумма.

### Пример

Ввод:

```text
3
1
2
3
```

Вывод:

```text
6
```

```som
// Задача 15-jami-ruykhat: Сумма списка
// Напишите свою программу здесь
```

Ввод:

```text
3
1
2
3
```
