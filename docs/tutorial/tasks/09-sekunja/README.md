# Секунҷа / Треугольник

## Масъала 09-sekunja: Секунҷа

Се тарафро хонед. Агар аз онҳо секунҷа сохтан мумкин бошад (ҳар тараф аз ҷамъи
ду тарафи дигар хурдтар аст), `Ҳа`, вагарна `Не` чоп кунед.

**Вуруд:** Се рақам, ҳар кадом дар сатри алоҳида.

**Натиҷа:** `Ҳа` ё `Не`

### Мисол

Вуруд:

```text
3
4
5
```

Натиҷа:

```text
Ҳа
```

```som
// Масъала 09-sekunja: Секунҷа
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
3
4
5
```

Агар Node.js ва SomonScript насб бошанд, барномаро бо ҳамаи санҷишҳо месанҷед:

## Задача 09-sekunja: Треугольник

Прочитайте три стороны. Если из них можно составить треугольник (каждая сторона
меньше суммы двух других), выведите `Ҳа`, иначе `Не`.

**Ввод:** Три числа, каждое в отдельной строке.

**Вывод:** `Ҳа` или `Не`

### Пример

Ввод:

```text
3
4
5
```

Вывод:

```text
Ҳа
```

```som

```

Ввод:

