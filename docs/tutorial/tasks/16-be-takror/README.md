# Бе такрор / Без повторов

## Масъала 16-be-takror: Бе такрор

Рақамҳоро ба рӯйхат хонед ва ҳар рақамро танҳо як бор, бо тартиби аввалин пайдо
шуданаш, чоп кунед.

**Вуруд:** Сатри аввал — шумораи рақамҳо `н`, баъд `н` сатр, дар ҳар кадом як
рақам.

**Натиҷа:** Рақамҳо бе такрор.

### Мисол

Вуруд:

```text
6
1
2
1
3
2
1
```

Натиҷа:

```text
1
2
3
```

```som
// Масъала 16-be-takror: Бе такрор
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
6
1
2
1
3
2
1
```

## Задача 16-be-takror: Без повторов

Прочитайте числа в список и выведите каждое число только один раз, в порядке
первого появления.

**Ввод:** Первая строка — количество чисел `н`, затем `н` строк, в каждой по
числу.

**Вывод:** Числа без повторов.

### Пример

Ввод:

```text
6
1
2
1
3
2
1
```

Вывод:

```text

2
3
```
