тақсим шавад ва ба 100 не, ё ба 400 тақсим шавад.

## Задача 09-kabisa: Високосный год

Прочитайте год и выведите `Кабиса` (високосный) или `Кабиса нест`. Год
високосный, если делится на 4, но не на 100, или делится на 400.

**Ввод:** Одно число: год.

**Вывод:** `Кабиса` или `Кабиса нест`

### Пример

Ввод:

```text
2024
```

Вывод:

```text
Кабиса
```

```som

// Напишите свою программу здесь
```

Ввод:

```text

```
