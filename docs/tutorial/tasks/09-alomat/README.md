# Аломати рақам / Знак числа

## Масъала 09-alomat: Аломати рақам

Рақамро хонед ва `Мусбат`, `Манфӣ` ё `Сифр` чоп кунед.

**Вуруд:** Як рақам.

**Натиҷа:** `Мусбат`, `Манфӣ` ё `Сифр`

### Мисол

Вуруд:

```text
5
```

Натиҷа:

```text
Мусбат
```

```som
// Масъала 09-alomat: Аломати рақам
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
5
```
