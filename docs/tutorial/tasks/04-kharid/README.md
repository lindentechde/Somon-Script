# Харид / Покупка

## Масъала 04-kharid: Харид

Дафтар 3 сомонӣ ва қалам 2 сомонӣ меистад. 5 дафтар ва 4 қалам харидем. Ҳамагӣ
чанд сомонӣ пардохтем? Чоп кунед: `Ҳамагӣ: …`.

**Вуруд:** Нест.

**Натиҷа:** `Ҳамагӣ: …`

### Мисол

Натиҷа:

```text
Ҳамагӣ: 23
```

```som
// Масъала 04-kharid: Харид
// Барномаи худро ин ҷо нависед
```


## Задача 04-kharid: Покупка

Тетрадь стоит 3 сомони, ручка — 2 сомони. Купили 5 тетрадей и 4 ручки. Сколько
сомони заплатили всего? Выведите: `Ҳамагӣ: …`.

**Ввод:** Нет.

**Вывод:** `Ҳамагӣ: …`

### Пример

Вывод:

```text
Ҳамагӣ: 23
```

```som
// Задача 04-kharid: Покупка
// Напишите свою программу здесь
```

[▶ Решить в песочнице](https://lindentechde.github.io/Somon-Script/#c=Ly8g0JfQsNC00LDRh9CwIDA0LWtoYXJpZDog0J_QvtC60YPQv9C60LAKLy8g0J3QsNC_0LjRiNC40YLQtSDRgdCy0L7RjiDQv9GA0L7Qs9GA0LDQvNC80YMg0LfQtNC10YHRjAo&t=W3siaSI6IiIsIm8iOiLSstCw0LzQsNCz06M6IDIzXG4ifV0)

В песочнице кнопка **✓ Санҷидан** («Проверить») проверяет программу на всех
тестах этой задачи.

### Проверка на компьютере

Если установлены Node.js и SomonScript, программа проверяется на всех тестах:

```bash
npm run check-task -- 04-kharid барнома.som
```
