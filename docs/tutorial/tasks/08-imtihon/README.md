# Имтиҳон / Экзамен

## Масъала 08-imtihon: Имтиҳон

Холи имтиҳонро хонед. Агар хол 50 ё зиёда бошад, `Гузашт`, вагарна `Нагузашт`
чоп кунед.

**Вуруд:** Як рақам: хол.

**Натиҷа:** `Гузашт` ё `Нагузашт`

### Мисол

Вуруд:

```text
50
```

Натиҷа:

```text
Гузашт
```

```som
// Масъала 08-imtihon: Имтиҳон
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
50
```

Прочитайте балл за экзамен. Если балл 50 или больше, выведите `Гузашт`, иначе
`Нагузашт`.

**Ввод:** Одно число: балл.

**Вывод:** `Гузашт` или `Нагузашт`

```text
50
```
