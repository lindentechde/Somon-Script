# Баръакс / Наоборот

## Масъала 15-baraks: Баръакс

Рақамҳоро ба рӯйхат хонед ва онҳоро бо тартиби баръакс, ҳар кадом дар сатри
алоҳида, чоп кунед.

**Вуруд:** Сатри аввал — шумораи рақамҳо `н`, баъд `н` сатр, дар ҳар кадом як
рақам.

**Натиҷа:** Рақамҳо бо тартиби баръакс.

### Мисол

Вуруд:

```text
3
1
2
3
```

Натиҷа:

```text
3
2
1
```

```som
// Масъала 15-baraks: Баръакс
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
3
1
2
3
```

## Задача 15-baraks: Наоборот

Прочитайте числа в список и выведите их в обратном порядке, каждое в отдельной
строке.

**Ввод:** Первая строка — количество чисел `н`, затем `н` строк, в каждой по
числу.

**Вывод:** Числа в обратном порядке.

### Пример

Ввод:

```text
3
1
2
3
```

Вывод:

```text
3
2
1
```

```som
// Задача 15-baraks: Наоборот
// Напишите свою программу здесь
```

Ввод:

```text
3
1
2
3
```

В песочнице кнопка **✓ Санҷидан** («Проверить») проверяет программу на всех
тестах этой задачи.

### Проверка на компьютере

Если установлены Node.js и SomonScript, программа проверяется на всех тестах:

```bash
npm run check-task -- 15-baraks барнома.som
```
