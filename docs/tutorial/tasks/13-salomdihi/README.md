# Саломдиҳӣ / Приветствие

## Масъала 13-salomdihi: Саломдиҳӣ

Функсияи `саломДиҳ(ном)`-ро нависед, ки `Салом, ном!` чоп кунад. Ду номро хонед
ва функсияро барои ҳар кадом даъват кунед.

**Вуруд:** Ду сатр: ду ном.

**Натиҷа:** Ду саломдиҳӣ.

### Мисол

Вуруд:

```text
Алӣ
Зарина
```

Натиҷа:

```text
Салом, Алӣ!
Салом, Зарина!
```

```som
// Масъала 13-salomdihi: Саломдиҳӣ
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
Алӣ
Зарина
```
