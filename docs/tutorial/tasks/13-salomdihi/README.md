## Task 13-salomdihi: Greeting

("Hello, name!"). Read two names and call the function for each of them.

**Input:** Two lines: two names.

**Output:** Two greetings.

### Example

Input:

```text
Алӣ
Зарина
```

Output:

```text

Салом, Зарина!
```
