# Ҷамъ то сифр / Сумма до нуля

## Масъала 11-jam-to-sifr: Ҷамъ то сифр

Рақамҳоро як-як хонед, то `0` ояд. Ҷамъи ҳамаи рақамҳоро чоп кунед.

**Вуруд:** Рақамҳо, ҳар кадом дар сатри алоҳида; охиринаш `0`.

**Натиҷа:** Ҷамъ.

### Мисол

Вуруд:

```text
5
3
8
0
```

Натиҷа:

```text
16
```

```som
// Масъала 11-jam-to-sifr: Ҷамъ то сифр
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
5
3
8
0
```

## Задача 11-jam-to-sifr: Сумма до нуля

Читайте числа по одному, пока не встретится `0`. Выведите сумму всех чисел.

**Ввод:** Числа, каждое в отдельной строке; последнее — `0`.

**Вывод:** Сумма.

### Пример

Ввод:

```text
5
3
8
0
```

Вывод:

```text
16
```
