# Калонтарин дар рӯйхат / Наибольшее в списке

## Масъала 15-kalontarin: Калонтарин дар рӯйхат

Рақамҳоро ба рӯйхат хонед ва калонтарини онҳоро чоп кунед.

**Вуруд:** Сатри аввал — шумораи рақамҳо `н`, баъд `н` сатр, дар ҳар кадом як
рақам.

**Натиҷа:** Калонтарин.

### Мисол

Вуруд:

```text
4
3
9
2
9
```

Натиҷа:

```text
9
```

```som
// Масъала 15-kalontarin: Калонтарин дар рӯйхат
// Барномаи худро ин ҷо нависед
```

Вуруд:

```text
4
3
9
2
9
```

## Задача 15-kalontarin: Наибольшее в списке

Прочитайте числа в список и выведите наибольшее.

**Ввод:** Первая строка — количество чисел `н`, затем `н` строк, в каждой по
числу.

**Вывод:** Наибольшее.
