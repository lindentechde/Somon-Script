# Урок 5. Ввод: `хондан` и `хонданиРақам`

**В этом уроке:** программа получает данные от пользователя.

## `хондан()`

`хондан()` («читать») читает одну строку из поля «Вуруд» (ввод):

```som
тағ ном = хондан();
чоп("Салом, " + ном + "!");
```

Ввод:

```text
Алӣ
```

[▶ Запустить в песочнице](https://lindentechde.github.io/Somon-Script/#c=0YLQsNKTINC90L7QvCA9INGF0L7QvdC00LDQvSgpOwrRh9C-0L8oItCh0LDQu9C-0LwsICIgKyDQvdC-0LwgKyAiISIpOwo&i=0JDQu9OjCg)

- В песочнице ввод пишется в поле **«Вуруд»**: каждая строка — один ввод.
- Каждый вызов `хондан()` берёт следующую строку.

## `хонданиРақам()`

`хондан()` всегда возвращает **строку**. Для вычислений нужен `хонданиРақам()`
(«прочитать число»):

```som
тағ а = хонданиРақам();
тағ б = хонданиРақам();
чоп("Ҷамъ:", а + б);
```

Ввод:

```text
2
3
```

[▶ Запустить в песочнице](https://lindentechde.github.io/Somon-Script/#c=0YLQsNKTINCwID0g0YXQvtC90LTQsNC90LjQoNCw0pvQsNC8KCk7CtGC0LDSkyDQsSA9INGF0L7QvdC00LDQvdC40KDQsNKb0LDQvCgpOwrRh9C-0L8oItK20LDQvNGKOiIsINCwICsg0LEpOwo&i=MgozCg)

Если вместо `хонданиРақам()` написать `хондан()`, получится `23`, а не `5`: две
строки соединятся (вспомните урок 4).

Если во вводе не число, программа остановится с ошибкой: «`се` рақам нест:
`хонданиРақам()` рақам интизор буд» («`се` — не число»). Дробное число можно
писать с точкой или запятой: `2.5` или `2,5`.

## Вопрос

В `хондан` и `хонданиРақам` можно передать вопрос. Он выводится перед чтением:

```som
тағ синну = хонданиРақам("Шумо чандсолаед? ");
чоп("Пас аз 5 сол шумо", синну + 5, "сола мешавед.");
```

Ввод:

```text
13
```

[▶ Запустить в песочнице](https://lindentechde.github.io/Somon-Script/#c=0YLQsNKTINGB0LjQvdC90YMgPSDRhdC-0L3QtNCw0L3QuNCg0LDSm9Cw0LwoItCo0YPQvNC-INGH0LDQvdC00YHQvtC70LDQtdC0PyAiKTsK0YfQvtC_KCLQn9Cw0YEg0LDQtyA1INGB0L7QuyDRiNGD0LzQviIsINGB0LjQvdC90YMgKyA1LCAi0YHQvtC70LAg0LzQtdGI0LDQstC10LQuIik7Cg&i=MTMK)

**В задачах вопрос не пишите:** проверка сравнивает только вывод.

## Если ввод закончился

Если программа читает больше строк, чем есть в «Вуруд», будет ошибка: «Вуруд
тамом шуд» («ввод закончился»). Дайте программе столько строк, сколько она
читает.
