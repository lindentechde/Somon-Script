# Урок 11. Цикл `то`, `шикастан` и `давом`

**В этом уроке:** вы напишете цикл, число шагов которого заранее неизвестно.

## `то`

`то (условие) { … }` («пока») повторяет команды, пока условие `дуруст`:

```som
тағ шумора = 5;
то (шумора > 0) {
  чоп(шумора);
  шумора = шумора - 1;
}
чоп("Оғоз!");
```

Внутри цикла что-то должно меняться, чтобы условие однажды стало `нодуруст`.
Иначе цикл будет бесконечным.

## Цифры числа

```som
тағ адад = хонданиРақам();
тағ шумора = 0;
то (адад > 0) {
  адад = Риёзӣ.поён(адад / 10);
  шумора++;
}
чоп("Рақамҳо:", шумора);
```

Ввод:

```text
2026
```

## `шикастан`: выйти из цикла

```som
// Рақамҳоро то 0 мехонад ва ҷамъи онҳоро чоп мекунад
тағ ҷамъ = 0;
то (дуруст) {
  тағ рақам = хонданиРақам();
  агар (рақам === 0) {
    шикастан;
  }
  ҷамъ += рақам;
}
чоп("Ҷамъ:", ҷамъ);
```

Ввод:

```text
5
3
8
0
```

- `то (дуруст)` — цикл сам не закончится; из него выходят через `шикастан`
  («прервать»).
- `давом` («продолжить») заканчивает текущий шаг и переходит к следующему.
