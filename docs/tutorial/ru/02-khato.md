# Урок 2. Ошибки и комментарии

**В этом уроке:** вы прочитаете сообщение об ошибке и исправите её; напишете
комментарий в программе.

## Ошибки — это нормально

Ошибаются все программисты. Важно уметь прочитать сообщение об ошибке и
исправить её. В этой программе есть ошибка — запустите её:

```text
тағ синну = 15;
агр (синну > 14) {
  чоп("Шумо метавонед бозӣ кунед");
}
```

[▶ Запустить в песочнице](https://lindentechde.github.io/Somon-Script/#c=0YLQsNKTINGB0LjQvdC90YMgPSAxNTsK0LDQs9GAICjRgdC40L3QvdGDID4gMTQpIHsKICDRh9C-0L8oItCo0YPQvNC-INC80LXRgtCw0LLQvtC90LXQtCDQsdC-0LfToyDQutGD0L3QtdC0Iik7Cn0K)

Песочница (на таджикском) сообщит:

```text
Хато дар сатри 2:
  Дар ин ҷо `{` интизор набуд: шояд пеш аз он `;` намерасад.
    2 | агр (синну > 14) {
      |                  ^
  Маслиҳат: Шояд `агар`-ро дар назар доштед?
Барнома компайл нашуд: 1 хато.
```

Сообщение читается так:

1. **Хато дар сатри 2** — «ошибка в строке 2». Номер этой строки слева от
   программы станет красным.
2. Дальше — **что не так**.
3. Строка программы и знак `^` — **где именно в строке**.
4. **Маслиҳат** — подсказка, как исправить. Здесь `агар` («если») написано с
   ошибкой: `агр`.

Если переключить язык песочницы на русский, сообщения тоже будут на русском.
Замените `агр` на `агар` и запустите снова.

## Ошибка во время выполнения

Некоторые ошибки появляются только во время работы программы. Они называются
**ошибками выполнения** (`Хатои иҷро`):

```som
тағ номҳо = ["Алӣ", "Зарина", "Фарҳод"];
чоп(номҳо[5].дарозӣ);
```

[▶ Запустить в песочнице](https://lindentechde.github.io/Somon-Script/#c=0YLQsNKTINC90L7QvNKz0L4gPSBbItCQ0LvToyIsICLQl9Cw0YDQuNC90LAiLCAi0KTQsNGA0rPQvtC0Il07CtGH0L7QvyjQvdC-0LzSs9C-WzVdLtC00LDRgNC-0LfToyk7Cg)

Песочница скажет «Хатои иҷро дар сатри 2», что произошло, и даст подсказку.
Такие ошибки мы лучше поймём в следующих уроках.

## Комментарии

Комментарий — текст, который компьютер не выполняет. Его пишут для людей:

```som
// Ин барнома саломро чоп мекунад
чоп("Салом!"); // комментарий может стоять в конце строки

/* Многострочный
   комментарий */
```

[▶ Запустить в песочнице](https://lindentechde.github.io/Somon-Script/#c=Ly8g0JjQvSDQsdCw0YDQvdC-0LzQsCDRgdCw0LvQvtC80YDQviDRh9C-0L8g0LzQtdC60YPQvdCw0LQK0YfQvtC_KCLQodCw0LvQvtC8ISIpOyAvLyDQutC-0LzQvNC10L3RgtCw0YDQuNC5INC80L7QttC10YIg0YHRgtC-0Y_RgtGMINCyINC60L7QvdGG0LUg0YHRgtGA0L7QutC4CgovKiDQnNC90L7Qs9C-0YHRgtGA0L7Rh9C90YvQuQogICDQutC-0LzQvNC10L3RgtCw0YDQuNC5ICovCg)

- `//` — комментарий до конца строки.
- `/* … */` — комментарий на несколько строк.

## Частые ошибки и сообщения о них

| Ошибка                    | Сообщение                                     |
| ------------------------- | --------------------------------------------- |
| `чоп("Салом);`            | Нохунаки пӯшандаи `"` намерасад (нет кавычки) |
| `чоп("Салом";`            | Қавси пӯшандаи `)` намерасад (нет скобки)     |
| `агр (х > 1) {}`          | Маслиҳат: Шояд `агар`-ро дар назар доштед?    |
| `чоп(ном);` без `тағ ном` | Номи `ном` эълон нашудааст (не объявлено)     |
