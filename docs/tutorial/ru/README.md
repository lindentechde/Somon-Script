# Программирование на SomonScript: уроки для начинающих

Эти уроки — для тех, кто никогда не писал программ. В каждом уроке короткое
объяснение, примеры и задачи. Примеры запускаются одним нажатием в
**песочнице**: <https://lindentechde.github.io/Somon-Script/>. Ничего
устанавливать не нужно. Язык страницы песочницы переключается на русский.

Код программ на SomonScript пишется по-таджикски; в уроках объяснено, что значит
каждое слово.

_Эти уроки по-таджикски: [Дарсҳо бо забони тоҷикӣ](../tj/README.md)._

## Задачи и их проверка

Каждая задача — с тестами: [все задачи](../tasks/README.md). На странице задачи
есть условие, пример и ссылка в песочницу. Ссылка открывает песочницу с тестами
задачи: кнопка **✓ Санҷидан** («Проверить») проверяет программу на всех тестах и
говорит, какие прошли. Если на компьютере установлены Node.js и SomonScript,
программу можно проверить и командой:

```bash
npm run check-task -- 05-jam барнома.som
```
