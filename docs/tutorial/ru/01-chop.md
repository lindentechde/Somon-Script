# Урок 1. Первая программа

**В этом уроке:** вы напишете первую программу, запустите её и с помощью `чоп`
выведете на экран текст и числа.

## Что такое программа?

Программа — это список команд для компьютера. Компьютер выполняет их по одной,
сверху вниз.

## Песочница

Программы мы пишем и запускаем в **песочнице** (майдони озмоиш):
<https://lindentechde.github.io/Somon-Script/>. Она открывается в браузере,
ничего устанавливать не нужно. Слева пишется программа, справа — «Вуруд» (ввод)
и «Натиҷа» (вывод). Кнопка **▶ Иҷро** запускает программу. Язык страницы можно
переключить на русский.

## Команда `чоп`

```som
чоп("Салом, ҷаҳон!");
```

[▶ Запустить в песочнице](https://lindentechde.github.io/Somon-Script/#c=0YfQvtC_KCLQodCw0LvQvtC8LCDSt9Cw0rPQvtC9ISIpOwo)

- `чоп` («печатай») выводит то, что стоит в скобках, в «Натиҷа».
- Текст пишется в кавычках `"…"`. Текст в программировании называют **строкой**
  (`сатр`).
- Каждая команда заканчивается `;`.

## Несколько строк и числа

```som
чоп("Ман барномасозиро меомӯзам.");
чоп("Ин барномаи аввали ман аст.");
чоп(2026);
чоп(2 + 3);
чоп("2 + 3");
```

[▶ Запустить в песочнице](https://lindentechde.github.io/Somon-Script/#c=0YfQvtC_KCLQnNCw0L0g0LHQsNGA0L3QvtC80LDRgdC-0LfQuNGA0L4g0LzQtdC-0LzTr9C30LDQvC4iKTsK0YfQvtC_KCLQmNC9INCx0LDRgNC90L7QvNCw0Lgg0LDQstCy0LDQu9C4INC80LDQvSDQsNGB0YIuIik7CtGH0L7QvygyMDI2KTsK0YfQvtC_KDIgKyAzKTsK0YfQvtC_KCIyICsgMyIpOwo)

- Команды выполняются в том порядке, в котором написаны.
- Числа пишутся без кавычек. `чоп(2 + 3)` выводит ответ: `5`. А `чоп("2 + 3")`
  выводит текст как есть: `2 + 3`.

## Несколько значений в одной строке

```som
чоп("Ҷавоб:", 6 * 7);
чоп("Ман", 13, "сола ҳастам");
```

[▶ Запустить в песочнице](https://lindentechde.github.io/Somon-Script/#c=0YfQvtC_KCLSttCw0LLQvtCxOiIsIDYgKiA3KTsK0YfQvtC_KCLQnNCw0L0iLCAxMywgItGB0L7Qu9CwINKz0LDRgdGC0LDQvCIpOwo)

Значения через запятую выводятся в одной строке через пробел: `Ҷавоб: 42`.

## Частые ошибки

- Не закрыть кавычку: `чоп("Салом);`
- Написать `Чоп` или `chop`. Большие и маленькие буквы различаются: только
  `чоп`.
- Не закрыть скобку: `чоп("Салом";`

Если вы ошибётесь, песочница скажет, где ошибка. В следующем уроке научимся
читать эти сообщения.
