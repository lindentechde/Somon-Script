# Урок 3. Переменные

**В этом уроке:** вы будете хранить значения в переменных и менять их.

## Что такое переменная?

Переменная — коробка с именем, в которой хранится значение. Её объявляют словом
`тағ`:

```som
тағ ном = "Зарина";
тағ синну = 13;
чоп(ном);
чоп(синну);
чоп(ном, "—", синну, "сола");
```

[▶ Запустить в песочнице](https://lindentechde.github.io/Somon-Script/#c=0YLQsNKTINC90L7QvCA9ICLQl9Cw0YDQuNC90LAiOwrRgtCw0pMg0YHQuNC90L3RgyA9IDEzOwrRh9C-0L8o0L3QvtC8KTsK0YfQvtC_KNGB0LjQvdC90YMpOwrRh9C-0L8o0L3QvtC8LCAi4oCUIiwg0YHQuNC90L3RgywgItGB0L7Qu9CwIik7Cg)

- `тағ ном = "Зарина";` — объявляет переменную `ном` («имя») и даёт ей значение
  `"Зарина"`.
- `чоп(ном)` выводит значение переменной, а не слово «ном».

## Изменение значения

```som
тағ хол = 10;
чоп(хол);
хол = 15;
чоп(хол);
хол = хол + 5;
чоп(хол);
```

[▶ Запустить в песочнице](https://lindentechde.github.io/Somon-Script/#c=0YLQsNKTINGF0L7QuyA9IDEwOwrRh9C-0L8o0YXQvtC7KTsK0YXQvtC7ID0gMTU7CtGH0L7QvyjRhdC-0LspOwrRhdC-0LsgPSDRhdC-0LsgKyA1OwrRh9C-0L8o0YXQvtC7KTsK)

- `хол = 15;` — даёт новое значение; `тағ` уже не нужен.
- `хол = хол + 5;` — берёт текущее значение, прибавляет 5 и снова сохраняет
  результат в `хол`.

## Константа

Значение, которое не меняется, объявляют словом `собит`:

```som
собит рӯзҳоиҲафта = 7;
чоп("Дар як ҳафта", рӯзҳоиҲафта, "рӯз ҳаст");
```

[▶ Запустить в песочнице](https://lindentechde.github.io/Somon-Script/#c=0YHQvtCx0LjRgiDRgNOv0LfSs9C-0LjSstCw0YTRgtCwID0gNzsK0YfQvtC_KCLQlNCw0YAg0Y_QuiDSs9Cw0YTRgtCwIiwg0YDTr9C30rPQvtC40rLQsNGE0YLQsCwgItGA06_QtyDSs9Cw0YHRgiIpOwo)

Если дать `собит` новое значение, песочница покажет ошибку.

## Имя переменной

- Имя состоит из букв, цифр и `_` и начинается с буквы: `ном`, `хол2`,
  `шумораи_хонандагон`, `рӯзҳоиҲафта`.
- Выбирайте понятные имена: `синну` («возраст») лучше, чем `х`.
- Ключевые слова (`тағ`, `агар`, `чоп` …) нельзя использовать как имена.

## Частые ошибки

- Использовать переменную до объявления: `чоп(х); тағ х = 1;`
- Дважды объявить одно имя через `тағ`.
- Написать `чоп("ном")` вместо `чоп(ном)`: кавычки выводят текст.
