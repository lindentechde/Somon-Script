# Lesson 11. The `то` loop, `шикастан` and `давом`

**In this lesson:** you will write a loop when you do not know in advance how
many steps it will make.

## `то`

`то (condition) { … }` ("while") repeats the commands while the condition is
`дуруст`:

```som
тағ шумора = 5;
то (шумора > 0) {
  чоп(шумора);
  шумора = шумора - 1;
}
чоп("Оғоз!");
```

Something must change inside the loop, so that one day the condition becomes
`нодуруст`. Otherwise the loop never ends.

## The digits of a number

```som
тағ адад = хонданиРақам();
тағ шумора = 0;
то (адад > 0) {
  адад = Риёзӣ.поён(адад / 10);
  шумора++;
}
чоп("Рақамҳо:", шумора);
```

## `шикастан`: leaving the loop

```som
// Reads numbers until 0 and prints their sum
тағ ҷамъ = 0;
то (дуруст) {
  тағ рақам = хонданиРақам();
  агар (рақам === 0) {
    шикастан;
  }
  ҷамъ += рақам;
}
чоп("Ҷамъ:", ҷамъ);
```

Input:

```text
5
3
8
0
```

[▶ Run in the playground](https://lindentechde.github.io/Somon-Script/#c=Ly8gUmVhZHMgbnVtYmVycyB1bnRpbCAwIGFuZCBwcmludHMgdGhlaXIgc3VtCtGC0LDSkyDSt9Cw0LzRiiA9IDA7CtGC0L4gKNC00YPRgNGD0YHRgikgewogINGC0LDSkyDRgNCw0pvQsNC8ID0g0YXQvtC90LTQsNC90LjQoNCw0pvQsNC8KCk7CiAg0LDQs9Cw0YAgKNGA0LDSm9Cw0LwgPT09IDApIHsKICAgINGI0LjQutCw0YHRgtCw0L07CiAgfQogINK30LDQvNGKICs9INGA0LDSm9Cw0Lw7Cn0K0YfQvtC_KCLSttCw0LzRijoiLCDSt9Cw0LzRiik7Cg&i=NQozCjgKMAo)

- `то (дуруст)`: this loop never ends by itself. You leave it with `шикастан`
  ("break").
- `давом` ("continue") ends the current step and goes on to the next one.
